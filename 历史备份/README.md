# 历史备份

这里是迭代过程中留下的旧版本快照，**只用于追溯，不参与运行**。

- 命名规则：`原名_备份_<时间或触发事件>.<扩展名>`，时间戳形如 `20261125_2247`，事件形如 `T35落表前`、`改前`。
- 覆盖范围：验证器（`l1_deduce` / `l2_dimension` / `units`）、判分器（`align` / `grader` / `contract` / `defects_v1`）、知识表（公式库、符号白名单、别名绑定、定律适用条件、覆盖率映射）、采分点总表 xlsx、以及两次判分输出的整体快照（`out_备份_*`）。
- **不要 import 这里的模块**：真实路径是上一层目录里的同名无后缀文件。`git mv` 保留了每个文件的提交历史，需要看某次改动前后的差异时用 `git log --follow <路径>`。
- 为什么留着：这些快照对应「改之前是什么样」的证据，评估某次修改是否真的改善了结果时要用。

新增备份请直接放进本目录下对应的子目录，不要再散落在源码目录里。
