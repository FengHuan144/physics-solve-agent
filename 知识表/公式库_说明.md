## 6. 符号白名单的规范与归一化

70 个符号，类型分布：变量 47 / 参数 20 / 常量 3（g、Gc、kk）。

### 6.1 硬规则（脚本逐条校验）

- ASCII + 数字/字母后缀：`v0`、`v1p`、`m1`、`mu0`。
- 禁 Unicode 下标、撇号、希腊字符本体：`v₀`、`v'`、`θ`、`μ` 都不会出现在 `symbol_id` 里（只出现在「规范写法」列供人读）。
- 单位全部是 pint 串：`meter/second`、`newton`、`kilogram/meter**3`、`dimensionless`。**不写 `m/s`、不写中文。**
- 一个符号一个含义，同题内不混用大小写。

### 6.2 为绕开 sympy 保留名所做的改名（必须知道，否则会「解析成功但物理量被换掉」）

| 物理量 | 常规写法 | 本表 symbol_id | 原因 |
|---|---|---|---|
| 支持力/正压力 | N | `Nf` | `N` 在 sympy 里是数值求值函数，`parse_expr("f-mu*N")` 直接抛 SympifyError |
| 摩擦生热 | Q | `Qheat` | `Q` 是 assumptions 对象 |
| 能量 | E | `Ek` / `Ep` / `Eini` / `Efin` | 单字母 `E` 会被**静默**解释成自然常数（不报错，最危险） |
| 末态总能量 | E₁ | `Efin` | `E1` 是指数积分函数 |
| 引力常量 | G | `Gc` | 与重力 G 撞名 |
| 碰后速度 | v₁′ | `v1p` | 撇号无法进 sympy |
| 力三角形对角 | α / β | `angA` / `angB` | `beta` 是 sympy 函数类 |
| 半长轴 | a | `asemi` | 与加速度 a 撞名 |
| 开普勒常量 | k | `kk` | 与劲度系数 k 撞名 |
| 平均速度 | v̄ | `vavg` | `\bar` 在 LaTeX 子集外 |
| 中间时刻速度 | v_{t/2} | `vmid` | `v_{t/2}` 的下标含 `/`，子集外 |
| 连续相等时间间隔 | T | `tau` | 与周期 T、绳张力 T 撞名 |

校验脚本里有一道**保留名黑名单**（`E I N S Q O C beta gamma zeta Lambda oo lambda`）：表达式里出现这些整词直接判 FAIL。这道检查比 R3 的「符号闭合」更要紧——闭合检查只看「有没有未在册符号」，而 `E`、`I` 会被解析成常量/虚数单位，符号集反而是空的，**查不出来**。

### 6.3 题目专用下标的处理（待裁定项，见 §10）

## 9. 一个容易踩的坑：`1/2` 与 `Rational(1,2)`

R2 要求分数写 `Rational(1,2)` 或 `S(1)/2`。本表 75 条全部用 `Rational(1,2)`（共出现在 10 条含 ½ 系数的式子里：F-002 F-004 F-005 F-008 F-042 F-043 F-045 F-046 F-055 F-071），无一处裸写 `1/2`，也无一处浮点。校验脚本对每条式子做两次解析（`evaluate=False` 与默认），比对 free_symbols 是否一致——若有人手改成 `1/2`，sympy 会按有理数算，**不会报错**，但若改成 `0.5` 就会引入浮点，量纲与约分都会失真。这一项无法自动判「你想写的是分数还是浮点」，只能靠本段约定。
