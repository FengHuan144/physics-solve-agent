# 定律表 `关联公式` 列重填记录

> 日期：2026-11-25 ｜ 执行：T00 总指挥 ｜ 备份：`知识表/定律适用条件_v1_备份_改前.csv`

## 为什么重填

`定律适用条件_v1.csv` 的 `关联公式` 列填的是 **T10 需求清单编号**（`公式库_需求清单.csv`，T10 交给 T09 的输入契约），而 `公式库_v1.csv` 用的是 **T09 实际编号**。两份自 F-006 起整体顺延：T09 在 F-006 前插入了「平均速度/中间时刻速度」等条目。

后果：12 条定律里 **10 条引用指向了别的公式**。最典型的是

- L-09 机械能守恒 → 实指 F-041 瞬时功率、F-043 动能定理、F-044 重力势能、F-045 弹性势能，**真值是 F-046**
- L-06 圆周运动 → 实指 相遇追及、脱离球面临界、往返对称、天体表面 g，**没有一条向心力**

`check_laws.py` 只验 id 是否存在、不验语义，所以报「外键 12/12 全过」。这条检查本身也有问题，已一并修订：OK 文案改为「id 存在（不校验语义）」。

## 重填规则（C12）

1. 需求 id → T09 实际 id，按 `公式库_外键对照_T09-T10.csv` 机械映射。
2. 对照表里 **8 条「T09 未收」** 的结构性式子，按下表挂等价式，不许直接抄需求编号。

| 需求 id | 名称 | 处理 | 依据（对照表备注） |
|---|---|---|---|
| F-009 | 竖直上抛上升时间 | 挂 F-010 | 由竖直上抛速度式取 v=0 反解 |
| F-013 | 合力为零（平衡条件） | 挂 F-017;F-018;F-019 | 二力平衡 + 两方向分量承担 |
| F-014 | x 方向合力为零 | 挂 F-018 | 并入水平分量式 |
| F-048 | 功能关系 W_other=ΔE | 挂 F-043 | 动能定理 + 势能定义的合并式 |
| F-056 | 绳不松弛 T≥0 | 挂 F-036 | 与 v²=gR 等价 |
| F-060 | 引力提供向心力 | 挂 F-059;F-031 | 万有引力 + 向心力联立 |
