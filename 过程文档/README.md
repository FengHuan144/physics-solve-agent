## 阅读顺序

想知道**现在能不能跑、怎么跑** → 看根目录 `README.md`。
想知道**做到哪一步、哪些结论还没验过** → 看根目录 `STATE.md`（活文档，随进度更新）。
想知道**当时为什么这么定** → 按上表时间顺序读。

## 注意

- 这些文档里的数字和结论**停在各自落款时间**，之后的变化不一定回写。以 `STATE.md` 与实跑结果为准。
- 三份审核报告的独立性不同：`审核报告_20261126_独立审查_进度评判.md` 是唯一与执行线分离的第三方审查；`审核报告_20261126_全局复核.md` 由 T00 自己出具，文首已声明「不是独立第三方」；`审核报告_20261125_T05_T12a_T06a.md` 的出具人见文首。
- `G*_打勾稿` 只是「照抄用」的草稿，**闸门是否通过以用户逐条打勾为准**，不以稿子里的实况表为准。
