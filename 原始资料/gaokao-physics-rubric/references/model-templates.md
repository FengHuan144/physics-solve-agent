# 六类题型的拆步骨架

每类给：**骨架（步 → 采分点 → 分值）**、**必给方程清单**、**特有陷阱**。
骨架可直接套用，但**分值与步骤数要按具体题目调整**；骨架的作用是防止漏步和漏方程。

---

## 1. 单体多过程（斜面、传送带、板块、减速带、刹车类）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 过程划分：把运动分成几段，各段性质（匀加速/匀速/匀减速） | 1 |
| 2 | 每段的原始方程（牛顿第二定律 或 运动学公式） | 2×段数 |
| 3 | 段间衔接量（末速度/位移/时间） | 1—2 |
| 4 | 全程动能定理 或 功能关系（有摩擦生热、多个同类过程时必写） | 3 |
| 5 | 结果（含单位/方向） | 1—2 |

### 必给方程
- `F − μmg = ma`、`μmg = ma`
- `v = v₀ + at`、`x = ½at²`、`v² − v₀² = 2ax`
- 全程：`mgH − W_f = 0`、`Q = f·Δs相对`

### 陷阱
- **计数**：n 个物体有 n−1 个间距，不是 n 个。"50 个减速带 = 49 个 d"是高频失分点，单列一步。
- **摩擦生热用相对位移**，不是某个物体的位移。
- 传送带要分"能否共速"、"共速后是否继续相对滑动"，这是①类判断，单独给分。

## 2. 碰撞类（弹性、完全非弹性、多次碰撞递推）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 碰前速度（自由落体/运动学/前一过程结果） | 1—2 |
| 2 | 动量守恒原式（规定正方向） | 2 |
| 3 | 能量方程：弹性→动能守恒；非弹性→损失量 | 2 |
| 4 | 解出两速度，并取舍（"另一解不合题意"） | 2 |
| 5 | 后续过程（上升/下滑/追及）的动能定理或运动学 | 2—3 |
| 6 | 递推/归纳：第 n 次碰后的速度或位移规律 | 2 |
| 7 | 判据：累计位移 vs 容器长度 ⇒ 碰撞次数 | 2 |

### 必给方程
- `m₁v₁ = m₁v₁′ + m₂v₂′`
- `½m₁v₁² = ½m₁v₁′² + ½m₂v₂²`
- 弹性等质量结论：交换速度（可直接引用，但要注明"等质量弹性碰撞速度互换"）

### 陷阱
- **方向符号**：反弹后速度取负。这是②类里唯一"符号错即本步 0 分"的地方。
- 完全非弹性碰撞只写动量式，漏"共速"这一条件，扣 1。
- 多次碰撞必须写"第 n 次的规律"，只算到第二次给一半分。
- 判次数时，起始位置容易漏（盘距管口 l，不是 0）。

## 3. 弹簧连接体（含分离临界、质心法）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 状态判断：共速 ⇔ 形变最大 ⇔ 弹性势能最大 | 2 |
| 2 | 动量守恒求共同速度（或求未知质量） | 2 |
| 3 | 能量守恒求 Ep 或 v | 2 |
| 4 | 形变量：位移差 / 图像面积 / 质心法 | 2—3 |
| 5 | 分离条件：恢复原长、弹力为零、加速度相同但速度不同 | 2 |
| 6 | 分离后各自运动（动能定理/运动学） | 2 |
| 7 | 结果 | 1—2 |

### 必给方程
- `m₁v₁ = (m₁+m₂)v共`
- `Ep = ½m₁v₁² − ½(m₁+m₂)v共²`
- 质心法：`m₁s₁ + m₂s₂ = (m₁+m₂)v_c t`，`v_c = 常量`
- 分离临界：`x = 0`（原长）、`a相同且N=0`

### 陷阱
- **"共速"和"恢复原长"不是一回事**：共速对应势能最大，恢复原长对应分离/动能最大。混淆则整问归零。
- 压缩量是**相对位移**（两物体位移之差），只算一个物体的位移是最高频错误。
- v-t 图像题里，"面积=位移、两线间面积=形变"必须写成文字判断才得分。

## 4. 圆周运动 + 功能（竖直圆轨道、绳/杆模型、圆弧轨道）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 临界判断：绳模型最高点 `mg = mv²/R`；杆模型最高点 `v ≥ 0` | 2 |
| 2 | 向心力方程（在最高点/最低点） | 2 |
| 3 | 从释放点到该点的动能定理/机械能守恒 | 3 |
| 4 | 求速度或高度 | 1—2 |
| 5 | 轨道压力（牛顿第三定律） | 1—2 |

### 必给方程
- `mg + N = mv²/R`（最低点 `N − mg = mv²/R`）
- `mg(h) = ½mv²`
- 绳：`v_top ≥ √(gR)`；杆：`v_top ≥ 0`

### 陷阱
- 高度差要写清"下降了多少"，`mgR` 和 `mg(h+R)` 差一个 R，是 2025 甲 25 的高频错。
- 压力题必须写"由牛顿第三定律"，否则只得一半。
- 不脱离轨道的范围是**两段**（低速段 + 高速段），只写一段扣 1。

## 5. 天体与万有引力（比值、变轨、双星）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 基本方程：`GMm/r² = mv²/r = mω²r = m(4π²/T²)r` | 2 |
| 2 | 星球表面：`GM = gR²` | 1—2 |
| 3 | 比值式（写成一个式子，不要中途代数值） | 2 |
| 4 | 结果 | 1 |

### 陷阱
- 半径与高度的区别（`r = R + h`）。
- 比值题中途代入数值会失去过程分，要求"先写成比值再约"。
- 双星：周期相同、`m₁r₁ = m₂r₂`、`r₁ + r₂ = L`，三个式子缺一扣分。

## 6. 电磁学综合（复合场粒子、电磁感应双杆、导轨＋电容器）

### 骨架

| 步 | 采分点 | 分值 |
|---|---|---|
| 1 | 受力/场力分析（洛伦兹力方向、安培力方向） | 1—2 |
| 2 | 几何关系：半径 `r = mv/(qB)`、圆心位置、圆心角 | 2—3 |
| 3 | 运动学：`t = θm/(qB)`、`T = 2πm/(qB)` | 2 |
| 4 | （感应类）`E = BLv`、`I = E/R`、`F = BIL` | 2—3 |
| 5 | 动量定理求电荷量：`q = ΔΦ/R`、`BIL·Δt = mΔv` | 2 |
| 6 | 能量：`W安 = Q`、焦耳热分配 | 2 |
| 7 | 结果 | 1—2 |

### 陷阱
- 洛伦兹力不做功，但安培力做功——混用是概念性错误，判分口径要写明。
- 双杆题必须先判断"谁受安培力、方向如何"，符号错则后续全错。
- 电容器导轨：`q = CU = CBLv`，电流 `i = CBL·a`，这一步常被漏。

---

## 通用：一道题的"三层结构"

拆完步后回看，应能分成三层：

1. **建模型**（1—3 分）：判断过程性质、划分子过程。
2. **建方程**（8—12 分）：每条原式 1—3 分，占绝对多数。
3. **收结果**（2—4 分）：求解、单位、方向、取舍。

若某题第 2 层不足 60%，说明拆步把方程合并了，或者把"推导"当成了采分点——两者都会让学生在考场上"写了很多却没分"。
