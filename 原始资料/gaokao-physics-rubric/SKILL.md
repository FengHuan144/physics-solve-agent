# 高考物理采分点反推

把一道物理大题拆成"阅卷人真正会打勾的若干步"，每步给出**必须出现的式子或判断**、**分值**、**判分口径**。

> 前提事实：**高考评分细则（评卷用）从不公开**，公开的只有参考答案。所有采分点都是按"官方答案的分步结构 + 教辅解析标注的分步分值 + 按步给分规则"反推的。因此产出必须自带这句免责说明，且**分值允许 ±2 分误差，采分点的"有无"才是稳定项**。

## 开工前确认三件事

| 项 | 为什么必须问 | 默认值 |
|---|---|---|
| 范围 | 年份×卷别×题型，决定工作量 | 每年一卷、每卷一道纯力学计算题 |
| 用途 | 讲评课要"学生错在哪"，估分要"扣几分"，互批要"能打勾" | 讲评 + 互批 |
| 交付 | 讲义 HTML / 总表 xlsx / 两者 | 两者 |

范围模糊时不要自行扩大。一套卷通常只有一道纯力学计算题，另一道是电磁学；若用户说"所有力学大题"，先说明这个口径差异再动手。

**边界要在这一步写死**：纯力学册不收电磁感应压轴（即使含动量、含"安培力冲量"）；微元法题（变力冲量）超出常规列方程框架，应排除。否则第 0 步盘出来的池会混进不该收的题。

## 八步流水线

**0. 供给盘点（最容易漏，漏了后面全白干）**

先按"年份 × 卷别"拉**全部计算题的模型清单**，确认要考的模型五年内真的有计算题，再写选题清单。判据与坑见 `references/selection-playbook.md`。

- 只按知识点写愿望单、不核供给，结果多半是"清单 5 个坑，2 个五年没出过题"。
- 简谐运动、卫星变轨、受力平衡、纯自由落体，在高考里大量只出选择/填空，不能默认有计算题。
- 全国卷每年只有 2 道计算题（24 + 25），凑 20 道以上必须进省卷。
- 每题的"年份·卷别·题号·分值"必须过卷型骨架；分值对不上，先怀疑来源，不要怀疑骨架。
- 建池后做撞车检查（题号 + 分值 + 模型三重比对），撞车只能换题、不许改名。

**1. 定范围与口径**
列出"卷别·题号·分值·模型"清单，先给用户确认，再开始拆。口径要写清：纯力学（受力—运动—功与能为主线）还是宽口径（过程里出现力学即算）。

**2. 取题与答案**
按 `references/source-and-verify.md` 的来源分级检索。**至少两个独立来源交叉核对**题干与答案；只有一个来源的题，标注"待核"。

**3. 验算**
拿到答案先自己算一遍：量纲、极限情形（μ→0、m→∞）、能量守恒独立验算。**答案对不上就是题目转录错了**，不要拿错题继续拆。

**4. 定分值骨架**
从官方答案的分步结构读出每个小问的分值。总分必须等于卷面分（12 或 20 为主）。小问分值不确定时，按"步骤数 × 步骤权重"分配并标注为反推值。

**5. 拆步（最关键）**
把答案切成"可被判分的对象"，一步一个。判据：**这一步能不能在答题卡上被指认出来、单独打勾**。
- 一句判断、一条原始方程、一个必须算出的中间量、一个带单位的结果、一个临界条件——各算一步。
- 纯代数化简、移项、代入数值**不单独成步**，合并进"解得"。
- 一步只承担一个物理判断。若一步里塞了两个判断，拆开。

**6. 赋分 + 写判分口径**
每步 1—3 分，压轴步骤 2—3 分。判分口径必须能回答"**写成 X 给几分**"，而不是"要写对"。句式见 `references/rubric-taxonomy.md`。

**7. 校验 + 产出**
先跑 `scripts/validate_points.py`，全绿后跑 `scripts/build_workbook.py` 出总表；讲义按 `references/deliverable-spec.md` 的结构写。

## 五类采分对象（拆步检查清单）

| 类别 | 阅卷人在找什么 | 典型分值 |
|---|---|---|
| ① 状态判断 | "共速时势能最大""恢复原长时速度最大""平均速度相同即动能不变" | 1—2 |
| ② 原始方程 | 动量守恒、能量守恒、动能定理、牛顿第二定律的**原式**，一条一行 | 1—3 |
| ③ 过程量 | 碰前速度、位移、时间、质量比等必须算出的中间量 | 1—2 |
| ④ 结果规范 | 数值＋单位、矢量方向、多解取舍 | 1—2 |
| ⑤ 临界与范围 | 不等式、取值范围、临界条件、次数判据 | 1—2 |

一道 20 分题的健康分布：②占 ~40%、③占 ~30%、①占 ~15%、④⑤各 ~10%。若某题 ② 不足 30%，多半是拆步时把方程合并了。

## 四条铁律（写判分口径时的约束）

1. **等价给分**：同一物理关系的不同写法（动能定理 vs 能量守恒、文字表述 vs 公式）同等给分，口径里写明"…亦可"。
2. **不重复扣分**：同一错误只在一个采分点扣，后续按"错误传递"处理——用错值但方法对，仍给方法分。
3. **只看物理不看数学**：代数运算错不扣物理分，但**量纲错、三角函数配错、符号方向错**属物理错误，要扣。
4. **原始公式优先**：直接写结果不给过程分（最多给该步 1 分）；"由牛顿第二定律得"＋列式，比只列式更容易被认。

## 质量闸门（不过不许交付）

- [ ] 选题清单已过 G0：四要素齐全、分值过卷型骨架、双源一致、无撞车（`selection-playbook.md` 第十节）
- [ ] 每题采分点分值合计 == 卷面分值（脚本强制）
- [ ] 官方答案的每一步都有对应采分点，无漏步
- [ ] 每条判分口径都能回答"写成 X 给几分"，没有"视情况给分"这类空话
- [ ] 至少标出每题的"分水岭"步骤（哪一步错会导致后面全错）
- [ ] 免责与来源说明已写入交付物
- [ ] 不复制试卷原文（题干压缩改写、解答重新推导）

## 脚本与资源

```bash
python3 scripts/validate_points.py 采分点.csv       # 校验：合计、步号、类别、空口径、重复
python3 scripts/build_workbook.py 采分点.csv 输出.xlsx
```

- `assets/points_template.csv` — 录入模板（9 列），先填这个再生成
- `assets/lecture_template.html` — 讲义骨架（含打印样式、公式块、分值条、四列采分点表），复制后填内容
- `references/rubric-taxonomy.md` — 五类对象细则、判分口径句式库、分值分配经验
- `references/model-templates.md` — 六类题型的拆步骨架与必给方程清单
- `references/selection-playbook.md` — 供给盘点、卷型骨架速查、双源核对、撞车检查、档位定义、选题闸门
- `references/source-and-verify.md` — 来源分级、检索词、验算与转录陷阱
- `references/deliverable-spec.md` — 讲义 HTML 与总表 xlsx 的结构规范
