## 1. 结论先说

**同一个「可解释率」按三种读法算出三个数，闸的结论相反。这不是数据问题，是定义与另外两条规则互相打架，必须由人裁一个口径。**

| 口径 | 分子认什么 | 数 | ≥90%？ |
|---|---|---:|---|
| **R1 窄**（照定义字面） | 只认 ① 模型步 `equation.sympy` 原文、② 采分点口径原句 | **31/64 = 48.4%** | 不过 |

## 2. 三档差在哪：8 个「无方程」点

|---|---|---|---:|

## 3. 定义与另外两条规则的冲突（这是要你裁的真正问题）

**冲突一：`basis` 说不出出处时，到底允不允许 `na`。**
- T25 §3 硬约束 5：「每条 `basis` 要能落到总表 `判分口径` 的某一句话上。写不出出处的，`credit` 只能是 `na`。」
- 按字面，`na` 是「说不出出处」的合法归宿 → `na` 点天然不可解释。
- 但可解释率分母含 33 个 `na` 点 → 上限被锁死在 48.4%，闸 **永远不可能过**。

**冲突二：`L1/L2` 结论算不算合法依据。**
- T25 §4.1 判定优先级写明「第 2 顺位：候选步的 L1/L2 结论」——它明明是第一位的判定依据。
- 但可解释率定义只列了 `equation.sympy` 与口径原句两种来源，**没列 L1/L2 结论**。
- 按 §4.1 算 → R2（100%）；按定义字面算 → R1（48.4%）。

**冲突三：`na` 点要不要带 `by`。**
- §3 硬约束 3：「空数组只允许出现在 `credit=na` 或 `miss` 上」——允许 `na` 带空 `by`，不要求。
- 现在实现给 `na` 也填了 `by`（文本相似度选出的最优候选步），于是「无锚点」的 8 点有了一个指不出式子的 `by`，把可解释率从 100% 拖到 87.5%。
- 反过来说：若按硬约束 3 把它们置空，`by=[]` 也是一种「依据」（全题没有一步能承载），但它们就变成「没有归属」，可解释率怎么算又没定义。

## 4. 我的建议（未执行，等你裁）

**取 R3，并接受它现在不过闸。** 理由：
1. R1 会因冲突一被锁死在 48.4%，闸成了恒假命题，没有信息量。
2. R2 把「L1/L2 说 na」也算依据，等于只要写个步号就达标，闸失去区分力（64/64 全过）。
3. R3 卡在 87.5%，恰好指出一个真实短板：**8 个点归到了无式子锚点的步上**。这才是段 2 该修的东西，不是措辞。

**配套改一处实现（属于缺陷，不是刷分）**：`na / 无锚点` 且 `by` 步既无 `equation.sympy`、口径 2-gram 重合又低于某阈值时，`by` 置空、`basis` 写「全题 N 步无一步有式子锚点或与口径对得上」。这样「无归属」有据可查，而不是给一个指不出式子的步号。

**不建议**为了过闸去补 `L1/L2` 结论当依据——那是把闸的定义改宽，不是把判分器改对。

## 5. 复算方式

```
python - <<'PY'
import json,glob,sys; sys.path.insert(0,'.')
from 判分器 import grader as G
from 验证器 import runner as R
al=json.load(open('评测/对齐/T20步点对齐_v2.json',encoding='utf-8'))
HOME={p['point_id']:p['home'] for it in al['items'] for p in it['points']}
s=n=0; b=0
for p in sorted(glob.glob('判分器/out/*.json')):
    d=json.load(open(p,encoding='utf-8')); q=d['qid']
    doc,_=R.run_answer(json.load(open(f'评测/T20/out/{q}.json',encoding='utf-8')),alias=True,alias_qid=q)
    SM={x['step_id']:x for x in doc['steps']}
    for r in d['points']:
        if HOME.get(r['point_id']) not in ('1:1','1:n'): continue
        n+=1
        if any((SM.get(x,{}).get('equation') or {}).get('sympy') for x in r['by']): s+=1
        if '方程' in r['basis']: b+=1
print('R3',s,'/',n,'R1',b,'/',n)
PY
```

实测输出：`R3 56 / 64`、`R1 31 / 64`。
