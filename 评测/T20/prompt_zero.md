## 模板正文（发给模型的原文）

<!-- TEMPLATE_START -->
你是高中物理老师，请按步骤把下面这道题解出来，并顺手把题目本身的结构写清楚。

【你手上有的】
1. 题干与小问（见末尾）。**用户可能一个字都没打、只给了图**：末尾若只有「题干在图里，你自己读」这类占位话，就以图为准，把题干和小问逐字读进 `stem_text` 与 `sub_questions`。
2. 配图若干张（随后附上，依次标为「图甲」「图乙」…）。**图上能读出的数值就是数据**：题干没给的，必须从图上读。

【输出格式】
只输出一个严格 JSON，不要 markdown 代码块，不要任何解释性文字。结构如下：

```
{
  "stem_text": "题干原文，逐字，含各小问编号",
  "sub_questions": [{"no": "(1)", "text": "小问原文"}],
  "scores_printed": true,
  "objects": [{"name": "物块", "mass_symbol": "m"}],
  "sub_scores": [{"no": "(1)", "score": 4}],
  "givens": [{"symbol": "R", "value": 0.4, "unit": "m", "text": "轨道半径 R＝0.4 m"}],
  "sub_results": [{"no": "(1)", "result": "v = 4 m/s", "steps": [1, 2, 3]}],
  "steps": [
    {"no": 1, "title": "…", "kind": "judgment", "stmt": "…",
     "eq": null, "value": null, "score": 1, "point": "…"}
  ]
}
```

【字段规则】
- `stem_text`：把题干连同各小问**逐字抄一遍**，不改写、不概括、不解题。若用户没有贴文字、只能看图，这一项就是**你从图上读出来的题干**——读出来的、看不清的都照原样写，读不出就标「（字迹不清）」。
- `sub_questions`：每个小问的**原文**（去掉编号和「N 分」），与 `sub_scores` 一一对应，供页面显示。不要写「第 1 问所求量」这种占位话。
- `scores_printed`：题面是否印了分值。印了写 `true`；没印写 `false` —— 没印时 `sub_scores` 仍按你的判断给一个合理分配，但页面会注明「分值非题面所印」。
- `objects`：本题涉及的物体清单，每项 `{"name": "…", "mass_symbol": "…"}`；只列有质量的物体，桌面、斜面、地面这类不要列。没有可列的给空数组。
- `sub_scores`：每个小问的分值，`[{"no": "(1)", "score": 4}, …]`，必须与题干标注一致。
- `givens`：解本题用到的已知量清单。题干明确给出的写进来；从图上读出的也写，`text` 里注明「图上读出」。`value` 不知道就写 null，`unit` 无量纲写 "1"。
- `steps`：按解题顺序排列，一步只做一件能被阅卷老师单独给分的事。`no` 从 1 连续编号。
- `title`：≤ 14 字。
- `kind` 只能取下面四种：
  - `equation`：列原始方程。`eq` 必须非 null。
  - `value`：算出某个量的数值。`eq` 非 null，`value` 非 null。
  - `judgment`：判断、说明、指出来源。`eq` 必须为 null，`value` 为 null。
  - `discussion`：取舍与讨论（例如两根如何舍一根）。`eq` 至少写一个方程。
- `stmt`：这一步怎么想、怎么做，写给人看的话。允许写「由图乙读出」这类。
- `eq`：sympy 表达式，含义是「该式 = 0」。**不许出现等号，不许写 LaTeX**。乘法只用 `*`，幂用 `**`，除法用 `/`；分数系数写 `Rational(1,2)`，**不要写 0.5，不要写任何小数**。一步里有多个方程时，把各式的「左边减右边」相加。
  例：`3mg = mv²/R` 写成 `3*m*g + m*g - m*v**2/R`
- `value`：`{"symbol":"v","number":4,"exact":null,"unit":"m/s"}`。`number` 是数值（没有就 null），`exact` 是精确值字符串（如 `"9/2"`、`"sqrt(2*g*R)"`）。`unit` 只用 ASCII：`m/s`、`m/s^2`、`kg`、`N`、`J`。
- `score`：这一步值几分，可以是 0.5 的倍数。
- `point`：一句话说清这一步的采分点 —— 阅卷老师凭什么给这一分。

【符号怎么起名】
- **优先用题干里出现的符号**（题干写 v_B 就写 v_B，写 μ 就写 mu）。题干没给、由你引入的中间量，用「物理量英文 + 位置/方向」的短名，例如 `a_up`（上滑加速度）、`a_down`（下滑加速度）、`v_B_prime`（回到 B 点的速度）。
- 同一个量在 `givens`、`steps`、`sub_results` 里必须用同一个名字，不许一处 `v_B` 一处 `vB`。
- `stmt` 里第一次出现某个自定义符号时，用中文说明它是什么。

【分值】题干标注了分值就照它分配；**题面没印分值**（`scores_printed=false`）时，按各小问的推理量自己给一个合理分配，并在 `sub_scores` 里如实反映。无论哪种情况，每个小问内所有步的 `score` 之和必须等于该问分值，不得多也不得少。

【禁止】
- 不许编造图上没有的读数；读不出就写明读不出。
- 不许用「由对称性可知」「显然」这类没有依据的话跳过推理。

题干与小问：

{题干}
<!-- TEMPLATE_END -->

## 变量

- `{题干}`：用户粘贴的原文，原样放入；不做切分、不改写。可能是占位话（用户只给了图），以图为准。
- 图：用户上传的图片，按顺序附上，前缀文字「图甲」「图乙」。
