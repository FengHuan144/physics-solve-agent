## 8. R12 复算与 R8 敏感性

R12 规定 B-20 属“图即数据源”，其错误不计入任何能力统计。下表把四种口径并列，避免把“补图数据”混进能力读数。**主表（§1–§7）一律用口径 A（R12）**。

| 变体 | 口径 A：R12（countable=0 退出） | 口径 B：原样（不排除） | 口径 C：剔除 B-20 整行 | 口径 D：B-01/B-09 回退 undecidable |
|---|---|---|---|---|
| v1 | 19/21 = 90.5% | 20/22 = 90.9% | 19/21 = 90.5% | 17/19 = 89.5% |
| v2 | 20/21 = 95.2% | 21/22 = 95.5% | 20/21 = 95.2% | 18/19 = 94.7% |
| v3 | 19/21 = 90.5% | 19/22 = 86.4% | 19/21 = 90.5% | 17/19 = 89.5% |

**口径 A 与口径 C 的差别是记账方式，不是数字**：两者分母相同，但口径 A 保留 3 行记录（含 v1/v2 的 `correct` 与 v3 的 `wrong(guessed_without_figure)`），能回答「模型会不会承认缺图」——实测答案是一次都没有。口径 C 删行使这个问题无法再被问到。

**v1/v2 的 B-20 为何不判 `undecidable`**：模型确实给出了与标准答案一致的数值。把 `correct` 改成 `undecidable` 会篡改事实（它答对了，只是靠补条件），因此用 `countable=0` 让事实与统计分开记录。v3 硬答且答错，按 R12 记 `wrong(guessed_without_figure)`，与 `input_missing` 分列。

### 8.1 R12′：判据从「题目类型」改为「图质量」（2026-11-25 15:46 用户批准）

原 R12 的判据是**题目类型**（「图即数据源题一律退出统计」），颗粒太粗：它把「图本身不合格」和「图文题」混成一类，等于给这类题判了**永久排除**——将来有高清准确的图也回不来。

R12′ 改为按**图本身**三个条件判，任一不满足即 `countable=0`：

| # | 条件 | 判法 | B-20 现状 |
|---|---|---|---|
| 1 | 关键点有**显式标注**（端点/折点/刻度印在图上） | 有标注 → 模型可走代数路线，该步可计入 | ✅ 三个端点 (0,0)(4,2)(8,6) 印在图上 |
| 2 | 图本身**作图误差 ≤ 2%** | 按图上标注点反算，与真值比 | ❌ **不合格**：斜率折合 0.485 / 0.994（真值 0.5 / 1.0），误差 3.0% / 0.6% → **真值不唯一** |
| 3 | **结构性读数**（折线几段、拐点个数）单独排除 | 该类步不计入，数值步可计入 | ❌ 模型 3/3 稳定答「3 段」（真值 2 段），且虚构 (8,6)→(10,8) |

**B-20 的结论不变，但理由换了**：不是「它属于图即数据源这一类」，而是**它这张图自己画得不准**（条件 2 不合格）。这对将来是好事——换一张作图准确的同型题，它可以回来。

口径 D 说明：B-01「4 号锥筒」、B-09「能到边框 a」按 R8 字面应判 `undecidable`。2026-11-25 裁定：**保留 label 做法，但判对的门槛提高到「充分必要匹配」**——只有结论没有依据的一律判 `wrong(insufficient_derivation)`。判据与六条证据见 §9.2。口径 D 仅作「若回退 R8 字面」的敏感性参考。

### 9.1 已定项的口径记录（#3 的裁定依据）

**#3 B-20 归类。** R12 原话只排除 `wrong`，字面执行的结果是：v1、v2 的 `correct` 照常计入，v3 的 `wrong` 不算。但三条都不是「会做」——v1 写「按原题图示条件」补出 M=1 kg、F=4 N、a=2 m/s²，v2 写「由图乙可知」补出 4 N / 2 m·s⁻²，v3 写「由题图乙」补出 4 N / **1** m·s⁻²。a–F 数据只在图上（§3 明写正文未给数值），补对是记忆或猜中，补错是猜错。只剔 `wrong` 等于让「猜得准」算成能力——等于闭眼投篮蒙进两个就报 100% 命中。

**15:44 用户裁 R12′ 的结论与此一致，但理由更硬**：不是「这类题不算」，而是**这张图自己画得不准**（折合斜率 0.485 / 0.994，真值 0.5 / 1.0，误差约 3%，超 R12′ 的 2% 门槛）。→ 整题剔除，含 2 条答对。整体剔除后为 v1 19/21 = 90.5%、v2 20/21 = 95.2%、v3 19/21 = 90.5%。

## 10. 结论（只写能由数据支撑的）

1. **准确率不是“模型会做压轴题”的证据。** 三个变体分别为 90.5% / 95.2% / 90.5%，但判分只看最终答案；v3/B-16 已证明“最终式对、附带化简错”会被判对。真实能力上限低于这张表。
2. **“依赖图 6 题会全错”的预判不成立。** 6 题里 5 题（B-04/B-09/B-15/B-17/B-18）的数值条件都在题干文字里，模型靠文字就能做；22 题样本内唯一真正的图数据源 B-20，三变体全靠补/猜（A-02 同为图数据源，但不在本批 22 题内，未参与评测）。缺图的损失集中在 B-20 这一类，不在“6 题”整体。
3. **模型不会说“我看不见图”。** 0/66 主动承认缺图；反而 4 次引用图作答（B-20 三个变体各一次，外加 v2/B-17），而 B-20 三次“读图”读出的数据互斥。产品上必须把“输入缺失检测”当成独立能力来做，不能指望模型自报。
4. **v3 带例题没有更好，但“差多少”取决于口径。** 原样口径 v3 19/22 = 86.4%，低于 v2 的 21/22 = 95.5%（差 9.1 pp）；按 R12 把图数据源题退出统计后，v3 19/21 = 90.5%、v2 20/21 = 95.2%（差 4.8 pp），差距收窄但方向不变。两种口径都不支持“v3 更强”。另 v3 输出显著更长（B-15 在 32768 下把预算全花在 reasoning 上）。单次采样不足以定论，但“加例题+加结构”不等于更稳。
5. **可以复现。** 题干指纹、prompt 原文、66 份 raw、判分与裁定表全部落盘；`run.py` 断点续跑不重复计费，`score.py` 读 raw + 裁定表出 66 行。

## 11. 过程审计（抽样加严）

前面各节的 `correct` 只判最终答案。本节回答一个问题：**这些「对」里，有多少是答案对、过程错？**记录见 `process_audit.csv`。

### 11.1 抽样方法

| 层 | 覆盖 | 做法 |
|---|---|---|
| 结论段全查 | 60 / 60 `correct` | 逐条读「结果 / 最终答案 / 讨论 / 检验」段，验算其中的每个附加断言 |
| 完整推导抽样 | 15 / 60（25%） | 7 条关键词信号命中优先 + 8 条随机（seed=20261125），逐条读全文 |
| 定向复核 | B-20 × 3 | 核图数据来源，见 §6.4 |

### 11.2 结果

| 项 | 数量 |
|---|---|
| 全查发现的实质瑕疵 | **1**（v3/B-16） |
| 抽样发现的新增瑕疵 | **0** |
| 已知输入缺失（不计为过程错） | 2（B-20 的 v1、v2） |

**唯一一处实质瑕疵：v3/B-16。** 结果段附带化简 `sinθ/(sinθ+μcosθ) = 1/(1+μ)` 是错的（漏了 tanθ，仅当 sinθ=1 时成立）。但它的最终式 `E₁/E₂ = sinθ/(sinθ+μcosθ)` 正确，所以按边界 2（只判最终答案）**保持 `correct`，标 `process_flaw`**，不改判定。

**一处需要单独说明但不是过程错：B-13。** v1/v2/v3 都同时给出 7.5 m/s 与 7.44 m/s，并在讨论里说明「拎起背包时这一瞬间的速度」两种理解。这是题干歧义，三变体都按标准理解取了 7.44，判 `correct`。

### 11.3 为什么不自动验算

试过：把全文纯数值等式抽出左值右式逐个 eval，60 条共命中 74 个等式，**误报 73 个**。原因是小问编号和公式编号被当成了等式左边——`(2) = 1/2×10×(1/3)²`、`E_k = 1/2(M+m₀)v²` 里的 `2` 都被匹配成左值。

这个失败本身有信息量：**过程验证靠正则做不出来**，必须靠 `(n)` 上下文识别、符号定义追踪和量纲检查，那就是 G3 验证器（T12a）的活，不是 T07 的范围。
本节因此退回人工，并如实标注覆盖率。

### 11.4 对准确率的影响

答案层 60 条 `correct` 里，全查确认 1 条过程有瑕疵，占 **1/60 = 1.7%**。按 Wilson 95% 区间，真实比例在 **0.3% – 8.9%** 之间。

| 口径 | v1 | v2 | v3 |
|---|---|---|---|
| 答案层（本报告主口径） | 20/22 = 90.9% | 21/22 = 95.5% | 19/22 = 86.4% |
| 能力层（扣过程瑕疵，点估计） | 20/22 ≈ 90.9% | 21/22 ≈ 95.5% | 18/22 ≈ 81.8% |

> 能力层那行只是**点估计**：v3 的瑕疵是在全查中命中的，v1/v2 未命中不等于没有——完整推导只覆盖了 15/60。真实值只会比答案层低，不会高。**不要把 81.8% 当精确值引用。**
