## 首屏：三个结论

### 1. 补点候选：0 个

101 个模型步里 `new` = **0**。没有一步做了金标之外的独立物理动作，所以**不需要改表**。

另有 **2 处额外读数**嵌在已有步里，不构成 `new` 步。两处都已裁定为**不补点**（R7 / R8）：

| 步 | 多出来的东西 | 金标为什么没有 | 裁定 |
|---|---|---|---|
| `B-20-S05` | 折点处 `a = 2 m/s²` 的读数 | 金标 S04 只登记「折点 F=4 N」，走的是 k₁/k₂/b₂ 三条斜率截距，不读折点纵坐标 | 不补（R7）。表里没这条就是没分；且补 2 分会让 B-20 按分变 15/14，超卷面 |
| `A-02-S01` | `t=2t₀` 时 A=2v₀、B=0.8v₀ 两条读数 | 不是「金标没有」——金标 S09/S10 已分别登记（「2v₀ 由图 (b) 在 2t₀ 处读出」「B 以 0.8v₀」）；是**表的点描述集中在一处、金标分散登记** | 不改金标（R8）。口径的给分条件只考核初速与共速 |

### 2. 冗余率：0.99%（`(dup 0 + meta 1) / 101`）

- `dup` = 0：没有一步是「同一式子换形」或「同一句话说两遍」。
- `meta` = 1：`A-02-S16`（复述滑回速度 v₀ + 声明重力总功为零，为后面两个能量式作依据）。
- **这个 0.99% 挂在一个判断上（R5）**：`B-02-S03`（`v₀=gt`）与 `S02`（`v₀−gt=0`）是同一式换形，判 split 维持，理由是金标 `B-02-S01.value.exact = g*t`，删掉 S03 这个形式就没有承载步了。若判 dup，冗余率翻到 **1.98%**。所以引用这个数字时必须带一句「dup=0 是 7 题 101 步里最接近 dup 的那条被留在 split 上的结果」，别写成量出来的结论。
- 含义：**模型的每一步都在做事**，多写不是这批模型糊分的方式。所以「学生多写不该扣分」这条在本题集上无法用数据支持——没有多写可扣；反过来也不能据此推断「多写就该扣」，因为样本里根本没出现。

### 3. point-centric 判分：可行，但必须按点聚合，不能按步扣

66 个点的分布（v2 裁定后）：

| home | 个数 | 占比 | 判分含义 |
|---|---|---|---|
| `1:1` | **32** | 48.5% | 一个 primary 步直接判 |
| `1:n` | **32** | 48.5% | 可判，但必须按点聚合（最多一个点被 5 步承载） |
| `merged` | **1** | 1.5% | **部分对无处分摊**，全表唯一一处 |
| `none` | **1** | 1.5% | 模型没写（不是点不可判） |

- **`merged` = 1（v1 是 0，R2 裁定改的）**：`A-02-S08` 一句「质心位移＝v₀t₀＝位移加权平均」同时充当金标 S06（判断，2 分）与 S07（方程解 s_B）的证据，删掉这条方程两点同时塌 → 真合并。**风险落在 S06**：模型只给「质心匀速」没给「相对简谐」，2 分里可能只拿 1，而它与 S07 共用一步，机械分摊判不出该扣 1 还是 0。S07 另有 S09 独立给值，仍是 1:n。
  - v1 把它标成 primary 是为了绕开原卡「merged 步要撑起 ≥2 个 home=merged 点」的断言。**那条断言已按 R2 改为「每个 merged 步至少承载 1 个 home=merged 点」**——原来那条会把这类形状逼成不敢报，merged 这一格永远是 0，等于白设。
- **唯一的 `none` 是 `B-20-S05`（2 分）**：三条读数（k₁=0.5、k₂=1、b₂=−2）只命中 k₂，k₁ 与 b₂ 在 17 步里完全没出现。性质是**模型没写**（不是点不可判）——模型改走折点 (4 N, 2 m/s²) 路线，把 μ 和 M+m 都解出来了，只是没按斜率/截距登记。**判 0 是表的登记口径所致，不是模型算错**（R7 不补点的理由见 §10 与裁定书）。
- **必须按点聚合的硬证据**：`B-20-S06`（1 分）被拆成 4 步，而采分点表口径写着「只解出部分量本步 0 分」——任何单步都判 0，只有把 M、m、μ 三个量凑齐才给分。按步扣分的判分器在这一条上会必错。

## §1 三条补充口径（卡面没写死，**已由 T00 裁定**）

卡 §5/§6 给了类别定义，但没给「一步同时服务两个点」「等价但字面不同」「混合点谁是 primary」的位置。下面三条是执行时的判断，**已逐条裁定**（裁定书 R1/R2/R3），v2 按下述文字执行：

1. **primary = 承载该点「不可替代证据」的那一步。** 值点在值上；判断点在判断句上；**混合点（金标里 value 与判断句同处一步）在口径 0 分条件所考核的那一块上**。其余承载步记 `split`。
   > 卡面原来只写「与金标 value 同量同值」，但 v1 自己就有 2 处给判断型/混合型点选了**不带值**的步（`A-08-S07`、`A-10-S07`）——实际执行的就是这条，文字写窄了。**改文字，不改数据。**
2. **合并 vs 复用**：判据是「**删掉这一步的这条式子/这句判断，两个点是否同时塌**」。同时塌 → `merged`；只塌一个（另一个有本步内或别处的独立证据）→ split/primary + 另一件事通过 `points[].by` 复用同一步。典型不是合并：`A-08-S08`（先给 a=−5 再给 t₁=0.2）、`B-09-S03`（一句里既给乙的 a=μg 又给滑行距离）、`B-12-S01`（判定「看作整体」删掉后仍成立，只塌 S02 的价值）。**全表唯一的合并是 `A-02-S08`**（R2）。**跨点复用步 16 个，见 §2。**
3. **等价形式**：模型给出与金标**字面不同**的式子，判 `primary` + `equiv_form=true`，note 标 `[等价形式]` 并写清是**三种里的哪一种**：
   - `A-02-S02` **同解不同路**（碰后分离时刻 vs 共速时刻，换一组质量就不同解）
   - `A-02-S14` **等价比替代**（相对速度等大反向，一维弹性碰撞的等价判据，全式无 ½mv²）
   - `A-02-S18` **合并式**（全程式，需先消去上滑式才等价）
   共 **3 条**，见 §5。`B-12-S09` 的 ½(m+M)v²=(m+M)gh 两边同除即 v²=2gh，属 §6.2 代数等价，**不算**（v1 误标，附录 A 已撤）。

> 裁定结果：口径 1 **改文字不改数据**；口径 2 **补上「同时塌」这个可操作判据**（原稿写「有可分辨的句子就不算」，会漏掉 A-02-S08）；口径 3 **认，但要分清三种性质**。

**另有一条观察（不是口径，是数据）**：金标自己有 2 处把同一事实登记进两个分——`A-02` 的 S06 与 S07 共用方程 `m·s_A+5m·s_B=6m·v₀t₀`，`B-12` 的 S05 与 S06 都登记 `v₁=8 m/s`。后果是模型一句话可以同时命中两个分，**「部分对」在这两处天然无处分摊**——不是模型的问题，是金标侧的重叠。前者已按 R2 标 merged；后者 S06 有独立值步，模型 S06 一步同时是两点证据，仍是 1:n。

## §11 卡面缺口（2 条，**均已裁定**）

### 缺口 1：`merged` 的定义与 §10.2 的断言，在「一步合并两点、其中一点另有下游步」上互相打架 → **已裁定 R2**

`A-02-S08` 只给一个方程 `m·s_A+5m·s_B=6m·v₀t₀`（并代入 s_A=9/25 v₀t₀）。这个方程**同时**是金标 S06（质心匀速判据）与 S07（解 s_B）的证据，模型没给它们分开的式子——按 §5.1 的字面定义，这是「真合并」。

而 §10.2 原要求「merged 步必须撑起 ≥2 个 `home=merged` 的点」。S07 另有 `S09` 独立给出 s_B=141/125 v₀t₀，它的 home 只能是 `1:n`；只有 S06 会是 `home=merged`。一个 merged 步 → 1 个 merged 点，原断言必失败。

**v1 的处理（已废）**：按断言优先标 `primary(S06)` + 复用，note 写「字面 merged、实按 primary 计」。
**R2 裁定**：改标 `merged`，断言放宽为「**每个 merged 步至少承载 1 个 home=merged 点**」，并补一条更硬的可操作判据（§1 口径 2）：「删掉这一步的这条式子/这句判断，两个点是否同时塌」。原断言要求所有被合并的点都失去独立步，这个要求本身错——真危险是「**有一个点**的部分对无处分摊」。

### 缺口 2：「结构隐含型判定」判据覆盖不了 → **已裁定 R6，算命中**

`B-09-S05` 要求「甲的运动分两段（碰前 0.4→0.3、碰后 0.1→0）」。模型全篇没有这句话，而是用 `S07`（碰前段）、`S09`（碰后段，且明确 v_after=0.1 不复用 0.3）、`S11`（总时间=t₁+t₂）把结构显式化。§6.3 只承认「有对应的方向/条件判断句」，对「用式子结构表达判定」没有判据。

**R6 裁定**：判 `home=1:n`（纯 split）就对了——依据是口径原文的两条 0 分条件都没踩，不是「意思差不多」。**但 §6.3 的判据本身要补**：把「用两段式子＋求和把分段结构显式化」列为与「判断句」等价的判定表达；否则同一件事在 `A-10-S06`（用 `v(nR)≈v(R)` 一句绑两个符号）、`B-20-S05`（用折点坐标替代斜率截距）上会重复出问题。
