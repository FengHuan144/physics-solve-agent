### 1.2 与卡面建议实现的两处偏离（必须说明）

**偏离一：残差尺度用 `expr`，不用 `e`。** 卡 §1.1 写的是 `_residual(e, prior)`；我用 `_residual(expr, prior)`。

原因：`e` 是**已代入**的结果，一旦折叠成一个数，`_scale(e)` 量到的就是残差自身，相对容差退化成「自比自」，任何非零残差都判 bad。实测（R5 场景，前序 `x=0.3333`、方程 `x−1/3`）：

```
_scale(e)    = 3.333333333332966e-05   → _residual(e)    = ('bad',  -3.33e-05)
_scale(expr) = 0.3333333333333333      → _residual(expr) = ('zero', -3.33e-05)
```

**照抄卡面代码，R5 仍会 fail。**

**偏离二：`zero` 分支补一条「本步值必须与前序值一致」。** 卡面代码只判方程残差；方程被前序满足时它直接 pass。但若本步写的是另一个值（前序 x=3、方程 `x−3=0`、本步却写 x=4），这个值与前序冲突，是 E-10。**我第一版照卡面写，实测判 pass，还输出「本步 x=4 与前序一致」——假话。** 补检查后判 fail，并加 R6 钉住。

两处都是方向性守卫（一处防 pass→fail 的假阳性，一处防 fail→pass 的假阴性），不是风格偏好。
