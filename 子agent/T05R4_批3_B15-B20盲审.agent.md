## 3. 判定方法：三步对

### 第一步 · 存在性

在 §6 标准答案原文里找：这个式子或判断，原卷答案/解析有没有用到。

| 情况 | 判 |
|---|---|
| 原文明确写了这个式子/判断 | 有依据 |
| 原文跳过（直接给结果），但要得到结果绕不开它 | 有依据（间接） |
| 原文用的是完全不同的解法 | **有依据但需标注**：「替代解法，本步在原卷解法中不出现」 |
| 原文压根不需要，也不是替代解法 | 无依据 ← 最严重 |
| 原文不全、查不到 | 无法判定，单列，不许硬判 |

> 一题多解很常见（尤其 B-17、B-18），**替代解法不许判成无依据**。

### 第二步 · 分值

| 检查 | 判据 |
|---|---|
| 与规范 §3 初值是否一致 | 不一致写「规范初值 X，表内 Y，理由…」 |
| 本题采分点合计是否等于卷面分 | **必须等于**。若要加分，必须同时指出从哪减，否则破坏闭合 |
| **② 分值**占比是否 ≥30% | 规范 §2 原文是「② 原始方程**分值**占比不得低于 30%」——**按分值算，不是按步数** |
| 单步分值是否在 **0.5—4** 分之间 | 规范 §3「单步分值 ≤4 且 ≥0.5（脚本 warn 线）」，两头都查 |

> **本批 6 题的预估值**（T00 从表里实算，供你比对，判错要说明）：② 分值占比 B-15 50%、B-16 58%、B-17 47%、B-18 64%、B-19 50%、B-20 57%，**全部过 30% 闸**，最低是 B-17。单步分值只有 1 和 2 两种，不触 ≤4 线。
> 若你算出与这里不同，先查自己是否用**步数**当了分母——本卡 v1 就犯过这个错（当时写 24/52＝46%，那是步数比）。

### 第三步 · 口径

| 情况 | 判 |
|---|---|
| 原文有口径，表内照录/同义 | 照录 |
| 原文有，表内**更严**（原文「也可以」，表内「必须」） | 改严 ← 违反 C15，报 |
| 原文有，表内**更松** | 改松，报 |
| 原文空，表内自撰 | 自撰，应标「口径 C 级：自撰」；没标就报 |
