## 3. 两个缺陷（不是一个）

### D1 判定错：sympy 的 `sin/cos` 被当成「未定义函数」

`draft_to_schema.py:141` 用 `e.atoms(sympy.Function)` 判「有没有未定义函数」。但 sympy 里 `sin` 本身就是 `Function` 的子类，`atoms(Function)` 会命中 `sin(theta)` 这棵应用树本身。

现跑对照：

```
AppliedUndef 对 sin(x): set()      ← 正确：sin 是已知函数
AppliedUndef 对 f(x)  : {f(x)}     ← 正确：只抓真·未定义
```

后果：**任何含 sin/cos/tan 的式子归一失败**，方程被置 null 并记 issue。
A-01 实测 12 步里 7 步含三角，**这 7 步全部归一失败**（no=2,3,6,7,9,10,11）。

影响面（题干原文实测「θ/sin/cos/tan/角」出现次数）：A-01 39、B-16 48、B-05 21、B-04 14、B-10 14 —— **13 题里 5 题会中招**，另 8 题为 0。

关键一条：**基线 7 题草稿里含三角的步数是 0**（A-02/A-08/A-10/B-02/B-09/B-12/B-20 全 0），所以首跑没暴露这个 bug。不修就开跑，13 题会在「三角方程保不保留」这一维上与 7 题不同构 —— 正好毁掉 G4 要的可比性。

### D2 崩溃：`discussion` 步 eq 归一失败时没有 None 保护

`draft_to_schema.py:326–342` 三路分支：

- `judgment/critical` → `eq_obj = None`（安全）
- `equation/value` 且 `eq_raw is None` → 记 issue + `eq_obj = None`（安全）
- **其余 → 直接 `to_latex(eq_raw)`**

`discussion` 落在第三路。eq 已被 D1 打成 None → `re.sub` 收 None → TypeError，整题不落盘。
A-01 第 11 步 `kind=discussion` 正是这一支。**没有 D2 保护，D1 的失败会从「丢方程」升级成「整题崩」。**
