## 0. 一句话与四条边界

**一句话**：Schema v1.1 的 7 类题型只验了 4 类（A-06 / A-08 / B-09 / B-12），剩下四类**一份样例都没有**。本卡把四类补齐，并给出两个缺口的结论——**证实或证伪，不许悬空**。

**边界（越界即作废）**

1. **不许改 `schema/answer.schema.json` 的结构**。加字段、改 `additionalProperties`、动 `required`，一律作废。`figures` 只有四个字段（`fig_no`/`caption`/`caption_source`/`is_required`），这是既定契约。
2. **不许改已有 4 份样例**（A-06 / A-08 / B-09 / B-12）。它们是回归锚点，改了就失去对比意义。
3. **不许手写 L1 残差**。`build()` 用 sympy 现算，算不平直接抛异常不写盘——这条在 T08b 已立，继续守。
4. **不许自己登记新符号**。需要新符号时列进交付物第 4 项，由 T09 归口登记；`NON_FORMULA_SYMBOLS` 是脚本常量，不是谁想加就能加。

## 2. 四类各要验什么

### 2.1 B-02（2025 北京 17，9 分，3 问）— 全符号 + 过程分段

| 项 | 内容 |
|---|---|
| 原文 | `采分点/题干原文/B-02_2025北京_17.md` |
| 难在哪 | 全程无一个数值。炸裂发生在最高点，A 水平飞出、B 自由落体，**同一起点两个不同运动** |
| 要验的 | `situation.given` 的 `value` 全填 `null`、在 `text` 里写清符号含义时，Schema 能否过校验；L1 全步 `na` 是否被 `validate_schema.py` 认（会不会被当成「没填」报错） |
| 已知 | T07 基线已独立确认本题是**单解**（不是多解题），别把它当多解用 |

### 2.2 A-10（2023 北京 20，12 分，3 问）— 万有引力 + 图非必需

| 项 | 内容 |
|---|---|
| 原文 | `采分点/题干原文/A-10_2023北京_20.md` |
| 难在哪 | 全符号 + 球体内质量分布 + 暗物质（`r=nR` 内含质量不等于总质量） |
| 要验的 | `law_ids` 能否指向万有引力那 8 条（`F-059`~`F-066`）；`assumptions`（均匀分布、r>R 速度不变）是否必须显式写 |
| 注意 | 本题**依赖图 = 否**（第 3 问文字已给「r>R 范围内恒星速度几乎不变」，缺图可解）。图清单里 `is_required` 必须填 `false`，别照着「有图＝必需」的老习惯填 |

### 2.3 B-20（2024 山东 17，14 分）— 图即数据源 ⚠️ 本卡的核心难点

| 项 | 内容 |
|---|---|
| 原文 | `采分点/题干原文/B-20_2024山东_17.md` |
| 难在哪 | 第 (2) 问的 a–F 图线，**两段斜率（0.5 kg⁻¹、1 kg⁻¹）与截距（−2 m/s²）只存在于图里**，正文一个数没给 |
| 已实测 | T07 基线报告里，三种变体（原题/扰动/无图）读出**两套互斥数据**——这是「图即数据源」最硬的证据 |

**这是契约缺口，不是补样例能解决的。** 现在的矛盾：

| 事实 | 出处 |
|---|---|
| `figures[].caption` 定死「**非输入·仅金标**」 | T05a R4、`schema/字段清单.md` |
| 但 B-20 的斜率截距是**解题必需输入** | B-20 原文 §8：`是否依赖图：是` |
| `figures` 只有四个字段，`additionalProperties: false` | `answer.schema.json` |
| `situation.given` 的 `text` 是自由文本，塞得进「由图乙读出」 | — 但这样**图读数伪装成题干给定** |
| `stem_sha256` 锁的是 `stem_text` | 题干原文里没有 0.5，扰动实验会认为「题干没变」 |

**你要做的不是选一个方案实现，而是把三条路各自的代价写清**：

| 方案 | 做法 | 代价 |
|---|---|---|
| **1** | 给 `figures[]` 加 `provides[]`（图提供了哪些量）或给 `given[]` 加 `source` 字段 | 改契约（`additionalProperties: false` 要放开），全部旧样例要重跑 |
| **2** | 图读数直接写进 `situation.given`，`text` 注明「图乙读出」 | 不改契约；但**题干指纹与实际输入脱钩**，扰动实验的对照组会失真 |
| **3** | 规定「图即数据源」的题不纳入 L1 数值回代，整题判 `na` | 不改契约；但等于**这类题永远测不了计算对不对**——27 题里有多少这类，要先数 |

**本卡只做一件事**：把 B-20 按方案 2 造出来（唯一不改契约的路），**并明确标注它是「临时可跑，等裁定」**。方案 1 与 3 的代价写成一段评估，不写代码。

> 如果你发现方案 2 连 `validate_schema.py` 都过不了（比如 `stem_sha256` 校验、或 `unit="kg^-1"` 不在 pattern 内），**停下来报**，别改 schema 去迁就。
