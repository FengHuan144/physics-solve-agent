## 2. 段 A 代码审读（不只跑数）

**① 插入位置是安全的。** `names` 来自 `expr.free_symbols`，所以「`sym` 在 `names` 里」等价于「本步方程含本步符号」；此时 `e` 已无自由符号，就意味着 `sym` 必在 `prior` 里。因此 pass 文案「本步 x=… 与前序一致」不是空话，不存在「符号不在前序却宣称一致」的路径。

**② 残差尺度用 `expr` 是对的。** `_residual()` 内部 `tol = 2% × _scale(expr, knowns)`；若照卡面传 `e`，`_scale` 量到的是残差自身，2% 容差退化成自比自。R5（前序 0.3333、方程 `x−1/3`）会从 pass 掉回 fail——这是**假阳性**方向，T33 的两处偏离里这一处是必须的。

**③ R6 的补检查也是必须的，而且卡面建议版真的会放过。** 我构造了 `prior x=3`、方程 `x−3`、本步写 `x=4`：卡面代码判 **pass**，还会输出「x=4 与前序一致」——这是**假阴性**方向，比假阳性危险。T33 补的值一致性检查把方向堵住了。

**④ 残余同根因一处，T33 已自曝（§3.3），我复现成立。** `_per_step_no_value()`（`l1_deduce.py:402`）收到的仍是已代入的 `e`，同一个「自比自」问题；构造用例（前序 0.3333、方程 `x−1/3`、无 value）会误判 fail。现网金标 0 处、产物 0 处，今天不咬人。**未修，等裁定（§6 E1）。**

**⑤ 一处过程瑕疵，不影响结论。** R6 是「先改后补测」，不是卡要求的「先写测试再改」；T33 回执 §1.3/§4 已如实自述（「R6 是之后我自测补的」），不算隐瞒。
