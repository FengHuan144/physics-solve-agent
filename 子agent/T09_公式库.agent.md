## 0. 一句话与三条边界

**一句话**：建两张表——**公式库**（70–80 条，每条含适用条件、失效反例、sympy 形式）与**符号白名单**（独立成表，L2 的唯一准入名单）；再写一个脚本，保证每条公式都能被 sympy 解析、且用到的符号全部在册。

**边界**

1. **不做 RAG、不建向量库**。方案已冻结：高中物理公式是闭集，模型不缺知识，缺的是适用条件判断。
2. **不写求解器**。你只保证「能被解析」，不负责解方程。
3. **不收电磁/热/光/原子**。这册只有力学（29 题口径）。

## 1. 开工前必须想清楚的三件事（都容易错）

### 1.1 公式库不是「公式大全」，是 29 题用到的闭集

收录判据只有一条：**至少被一道题的一个「② 原始方程」步用到，或该步的直接变形**。用不到的不收。收多了白名单就宽，模型写错符号也能通过，L2 直接失效。

做题顺序：先把 A-01~A-05 已拆的 51 步（在 `原始资料/五卷力学大题_采分点总表_v2.xlsx` → `采分点总表`）里的方程全部抽出来，再按知识点补全 22 题必用的公式，最后才允许补「同一模型的标准变体」。

### 1.2 **动量必须收**——这是本任务最容易误解的一处

`原始资料/agent.md` §4.3 写「已砍掉动量层，改为五层」。那句话指的是**原题库 .doc 的章节分层**（第 13 章「碰撞与动量守恒」计算题只有 2 道且是原子物理），**不是公式库范围**。

评测集里有 4 道动量题：A-02（两次碰撞+弹簧）、A-03（连续碰撞）、B-09（单次碰撞）、B-19（动量定理·篮球）。不收动量公式，这四题的方程无法回代，L1 直接缺一块。

**结论：公式库按 29 题实际用到的公式建，不按题库的五层建。**

### 1.3 符号白名单必须独立成表

同一个量在题干/解析里有四种写法：`v₀ / v0 / V0 / v_0`。公式级白名单管不住这个，只有符号级归一化才能。

所以：**公式表引用符号表的 `symbol_id`，符号表才是 L2 的准入名单。** 两张表都要交。

## 3. 表 2：符号白名单（`知识表/符号白名单_v1.csv`）

### 列定义（9 列）

| 列 | 说明 | 例 |
|---|---|---|
| `symbol_id` | 规范名，`symbol` 列的直接值 | `v0` |
| `规范写法` | 人读的写法（Unicode 上下标） | `v₀` |
| `含义` | 一句话 | 初速度 |
| `单位_SI` | **pint 可解析**，不写 `m/s` | `meter/second` |
| `量纲` | 基本量纲组合 | `[length]/[time]` |
| `类型` | 常量/变量/参数/下标量 | 变量 |
| `常见错误写法` | 分号分隔 | `v_0;V0;V₀` |
| `首次出现题号` | 一题 | A-01 |
| `备注` | | 与 vt 区分 |

### 符号规范（硬规则，脚本校验）

- **一律 ASCII + 数字下标**：`v0`、`mA`、`vA1`（第一次碰后 A 的速度）、`mu`、`theta`。
- **禁用**：Unicode 下标（`v₀`）、撇号（`v'`）、希腊字符本体（`θ`）、空格、中文。
- **大小写有语义**：`m` 质量、`M` 大质量；同题内不得混用。
- **单位必须是 pint 串**：`m/s`、`米/秒`、`N/kg` 一律不合格；写 `meter/second`、`newton/kilogram`。
- **一个符号一个含义**。同一题里 `v` 不能既表示物块又表示薄板；用 `vP` / `vQ` 区分。

## 4. 硬规则（编号即验收项）

- **R1 条数 70–80**。少于 70 说明漏了模型；多于 80 说明收了用不到的。
- **R2 sympy 解析率 100%**。`parse_expr(公式_sympy)` 不许抛异常。分数用 `Rational(1,2)` 或 `S(1)/2`，不许 `1/2`。
- **R3 符号闭合 100%**。`公式_sympy` 里出现的每个 Symbol，必须能在符号表找到；符号表里每个 `symbol_id` 必须至少被一条公式或一个题号引用（不留死行）。
- **R4 适用条件必须可判定**。「适用于一般情况」「注意使用条件」这类不算；要能回答 yes/no，如「接触面间有相对滑动」。
- **R5 失效反例必填且具体**。写不出反例的公式，不许进库——说明你还没想清它什么时候不能用。
- **R6 每条公式挂 ≥1 个 `law_id`**，且该 `law_id` 必须存在于 T10 的 12 条。
- **R7 每条公式挂 ≥1 个题号**（29 题范围内）。挂不上的，删掉。
- **R8 `公式_latex` 只用受限子集**：`\frac \sqrt \cdot \times \sin \cos \tan \le \ge \approx ^ _ { } \mu \theta \alpha \omega \Delta \pi` 与字母数字。禁 `\begin{aligned}`、`\text{}`、`\displaystyle`、`\left`、`\right`。
- **R9 不许一条公式两个等号**（如 `a = F/m = μg`）。拆成两条，或在备注写变形。

## 7. 已知陷阱

| # | 陷阱 | 实例/后果 |
|---|---|---|
| 1 | 把「五层」当公式库范围，漏掉动量 | A-02/A-03/B-09/B-19 无法回代 |
| 2 | `\frac{1}{2}` 写成 `1/2` | sympy 按整数除法得 0，答案全错还查不出来 |
| 3 | Unicode 下标直接进 sympy | `v₀` → SyntaxError，必须先归一化成 `v0` |
| 4 | 单位写中文 | `米/秒` → pint 解析失败，L2 整层不可用 |
| 5 | 公式与定律混一张表 | 「适用条件」放不下，最后退化成一句废话 |
| 6 | 为凑 70 条收力矩/刚体转动 | 29 题里没有刚体题，收了就是噪声 |
| 7 | 同一符号在两道题里含义不同却共用一个 id | 回代串题，错误无法定位 |
| 8 | 只写「正确形式」，不写「常见误用」 | 这张表就退化成教材目录，对质检没有增量 |
