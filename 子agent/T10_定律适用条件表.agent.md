## 0. 一句话与三条边界

**一句话**：为力学 12 条定律/定理各写一张「成立条件卡」——可判定的条件、一次一问的自检问句、不成立时该换什么、以及挂到具体题号的典型误用。

**边界**

1. **不写公式推导**。公式的符号形式归 T09；你只写「什么时候能用、不能用怎么办」。
2. **不做知识点讲义**。每行必须能拿去判一条解析的对错，不能只是正确但无用的陈述。
3. **不覆盖电磁/热/光/原子**。册子边界是力学。

## 2. 表结构（`知识表/定律适用条件_v1.csv`）

### 列定义（14 列，顺序固定）

| 列 | 说明 |
|---|---|
| `law_id` | `L-01` … `L-12` |
| `名称` | 与教材一致 |
| `一句话表述` | ≤40 字，不含推导 |
| `成立条件_1` | 可判定句 |
| `成立条件_2` | 可判定句 |
| `成立条件_3` | 可判定句（没有就留空，但 12 条里至少 8 条要 ≥3 条） |
| `否定式条件` | 必填：「若……则不能用」 |
| `自检问句` | 一次一问，yes/no |
| `不成立时替代` | 换成哪条定律/哪个方法 |
| `易混对象` | 常被混淆的另一条定律 |
| `典型误用` | 具体错法 + 题号 |

| `关联公式` | T09 的 `formula_id` |
| `涉及题号` | 分号分隔 |

### 填写示例（照这个粒度写，不要写得更笼统）

```
L-09 | 机械能守恒 | 系统内只有重力或弹力做功时，机械能总量不变
成立条件_1 | 研究对象是系统（单个物体或物体系），不是单个力
成立条件_2 | 除重力、弹力外，没有其他力做功（合力做功为零不等于没有其他力）
成立条件_3 | 系统内没有摩擦生热、没有非弹性碰撞
否定式条件 | 若存在滑动摩擦、空气阻力或非弹性碰撞，则不能用机械能守恒，改用能量守恒（计入 Q=f·Δs相对）
自检问句 | 这个过程里，除了重力（和弹簧弹力），还有别的力做功吗？
不成立时替代 | 动能定理（算合外力做功）或 能量守恒（含内能项）
易混对象 | 动能定理（不要求"只有重力做功"，但要求算清所有功）
典型误用 | 板块题里对物块单独用机械能守恒，漏掉摩擦生热（B-20）；A-08 传送带段误用
关联错误码 | E-13（末态能量漏项）；E-04（项遗漏）
关联公式 | F-042;F-044;F-045;F-046
涉及题号 | A-05;B-08;B-18
```

> ⚠️ **本示例的 formula_id 是真实值，不是格式占位符**（2026-11-25 修正：原示例写 `F-041;F-045`，按现行编号 F-041=瞬时功率、F-045=弹性势能，恰好是上一轮错列的原型，照卡填写会重新生产同一个 bug）。
> 任何 `formula_id` 一律以 `知识表/公式库_v1.csv` 的 `formula_id` 为准；`公式库_需求清单.csv` 是**废弃**的 T10 自拟编号，不得引用。

## 3. 硬规则（编号即验收项）

- **R1 正好 12 条**，`law_id` 从 L-01 连续到 L-12，不许跳号。
- **R2 每条 ≥2 条成立条件**，且**至少 1 条是否定式**（「若……则不能用」）。只写正面条件等于没写。
- **R3 自检问句必须一次一问**。「是否满足机械能守恒且无摩擦」不算——复合问句模型无法回答。
- **R4 「不成立时替代」必填**，且必须是**另一条定律或另一个方法**，不许写「重新分析」。
- **R5 典型误用必须挂题号**，且题号在 29 题范围内。挂不上的，说明这条定律在本册没有落点，回到 §1 重新论证是否该收。
- **R6 每条至少挂 1 个 `formula_id`**，且该 id 必须存在于 T09 公式库。
- **R7 关联错误码只从 21 条里选**（E-01~E-16、E-20~E-24），不许新造。
- **R8 不许把「适用条件」写成「注意事项」**。判据是：把这句话交给一个没学过物理的人，他能不能对照题干回答 yes/no。不能就重写。

## 6. 已知陷阱

| # | 陷阱 | 后果 |
|---|---|---|
| 1 | 写成教材定义 | 「机械能守恒：只有重力做功时机械能不变」——这是定义，不是判据 |
| 2 | 自检问句写成复合句 | 模型回答「部分满足」，等于没答 |
| 3 | 只说「不能用」，不说「用什么」 | 模型知道错了也不知道改什么，重写环节空转 |
| 4 | 动量守恒只写「合外力为零」 | 漏掉「某方向合外力为零则该方向守恒」，B-09/B-12 会误判 |
| 5 | 把「动量守恒」与「机械能守恒」写成互斥 | 弹性碰撞两者同时成立；写成互斥会让模型二选一 |
| 6 | 摩擦生热写成 Q = f·s（对地位移） | 必须是**相对路程**；这是 A-08/B-20 的头号错点，对应 E-04 |
| 7 | 竖直圆临界只写「恰好过最高点 v=√(gR)」 | 杆模型 v=0、绳模型 v=√(gR)、管道模型不同；A-09 是绳，写成杆就错 |
| 8 | 典型误用挂「通用」不挂题号 | 无法验证，也无法在归因时反查 |

## 7. 与 T09 的边界（别混）

| | T09 公式库 | T10 定律表 |
|---|---|---|
| 回答的问题 | 这个式子怎么写、符号是什么 | 这条定律什么时候能用 |
| 粒度 | 一个公式一行（74 行） | 一条定律一行（12 行） |
| 外键 | 引用 `law_id` | 引用 `formula_id` |
| 谁用 | L2 回代、符号白名单 | S2 建模、L5 人工判据 |

**不许合并成一张表**：合并后「适用条件」会被公式的符号说明挤掉，最后退化成一句「注意适用条件」。
