## 3. 项目是什么

### 3.1 一句话

给高中物理大题做**逐点判分**：把学生的解题过程切成步，每步对应采分点，机器判每点拿没拿到分，并指出错在哪一步的哪个式子。

### 3.2 产品形态（用户已定，勿重开）

| 项 | 定案 | 定案时间/依据 |
|---|---|---|
| 形态 | **单题解析页**（左栏题干+真题图+已知+分值；右栏依赖链+分步五层） | 2026-11-25 15:58 用户「撤叉，做解析页」 |
| 已废弃 | 红叉批改式 / 多题工作台 / 异常队列 / 审批流 | 同上；工作台被否两次 |
| 用户 | **老师为主，学生也能用**。禁止再说「分值和口径对学生无用」 | 15:44 用户裁定；我曾把这句自己的假设当事实，被纠正 |
| 交互要求 | 不显示扣分（扣分逻辑归 G4 阈值）、非卡片式、双击即开、单文件 HTML + 原生 JS | 14:14 / 14:17 用户定稿 |
| 数据形态 | 产品交付物是 **step 级 JSON**，解析页只是它的目视渲染 | 15:55 |

### 3.3 非目标（别自己加回来）

- 题库清洗（T11，13:32 用户裁「暂时只用真题」）
- 30 题规模：实际 **27 题实题**（A-07 撤销；B-11/B-14 查证缺口，用户裁定保留缺口不硬凑）
- 多题批处理、账号权限、统计看板

### 3.4 用户沟通偏好（很重要，照着做）

- **要结论与路径，不要过程叙述**。给能直接看的东西（文件 + 表格 + 图）。
- 偏好工程化拆分：有编号的阶段 + 设闸门（确认了再往下）+ 不静默统一（拿不准的留白标记交他裁定）。
- **不用无法证实的说法加份量**。禁语：「面试原题」「大厂必考」「业界共识」「大家都这么做」。说不出出处就不说。
- 被追问依据时**直接承认**「这条我没有出处」，不给似是而非的替代答案。
- 项目收尾后会要**三视角复盘**（可避免的细节 / 流程可优化 / 他的指令与提示词可优化），且要求**单列我方执行失误**、**如实标注规程里本来就有的条目**。

## 7. 状态机与调度

### 7.1 六态（状态不是描述，是权限）

| 状态 | 含义 | 谁能置位 | 允许的下一态 |
|---|---|---|---|
| `未开始` | 无产出，无人动 | 默认 | → `进行中` / `阻塞` |
| `进行中` | 有执行者，未交 | 你 | → `待验收` / `阻塞` / `未开始` |
| `阻塞` | 有明确外部依赖未满足 | 你（须写明阻塞物与解除条件） | → `进行中` |
| `待验收` | 交出产出，未判定 | 执行者报，你登记 | → `已完成` / `退回` |
| `已完成` | 过验收 | **仅你** | → `退回` |
| `撤销` | 决策层取消 | **仅用户** | 终态 |

**三条纪律**
1. **`待验收` ≠ `已完成`**。执行者说「做完了」只是进入待验收。出来必须有一条可执行的验收证据。
2. **`已完成` 也能退回**。下游跑不通就打回上游，不许在下游打补丁掩盖。
3. **子 agent 的产出不自动进入事实源**。新出现的文件在被你验收前只是「候选事实」。

### 7.2 优先级不是「谁急」，是「谁挡着别人」

| 级别 | 判据 | 处置 |
|---|---|---|
| **P0** | 关键路径上，无替代路径 | 立即开，其他都让 |
| **P1** | 关键路径上，有替代（可绕过/可降级） | 本批开，允许延后一轮 |
| **P2** | 不在关键路径，拖到后期会变 P0 | 排进空档，**不许连续两轮零推进** |
| **P3** | 只影响质量下限，不影响能否交付 | 明确写「本期不做」 |

**批次原则**：一批 ≤5 题 / ≤2 张表，一批只交一件事。每批交付必须同时给「产出路径 + 验收证据 + 遗留清单」，缺一项不进 `待验收`。执行者不能自己宣布「这批过了」。
