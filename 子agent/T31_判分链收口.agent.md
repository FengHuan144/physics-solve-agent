## 3. 段 1：S2 收口 —— credit 三态是这一段的全部内容

### 3.1 要先定的三件事（不许边写边定）

**① hit 的充分条件。**
裁定 D2：**金标 `steps` 只作定位/对照/结果规范，不得作 hit 的充分条件。**
换句话说：不能因为「模型这一步和金标那一步长得像」就判 hit。必须有一条**独立于金标**的依据，只能是：

- L1/L2 的 `pass` 结论（`验证器/runner.py` 产），或
- 采分点口径原文里写明的判据（如「未说明两处用同一 v₀ 本步 0 分」），或
- 结果规范（单位/方向/舍根）比对——这一条可以用金标 `value`，因为规范是客观的

> **为什么 C03 能测 credit**：`½a₂t − L/6` 与金标 A-06-S04 只差一个系数，
> 文本、符号、结构都高度相似——**任何按相似度判 hit 的实现都会把它判成 hit**。
> 但它的量纲是 `m/s` 对 `m`，L2 必须判 `fail` + `E-12`（`验证器/tests/test_l2_coeff.py:87/132` 已钉住）。
> 所以它同时测两件事：① L2 没退化；② **credit 尊重了 L2 的 fail，没绕过去自己判 hit**。
> 这两件事缺一不可，所以它是段 1 唯一不可省的反例。

**② miss 的条件。**
模型有承载该点的步，且该步被 L1/L2 判 `fail`，或口径要求的要素明确缺失。
**「找不到步」不是 miss，是 `na`。** 这是本项目最容易搞混的一处。

**③ `na` 的六个原因标签**（`grader.py:43` 已定义，直接用，不许新增）：

| 标签 | 何时用 |
|---|---|
| `未实现` | 段 1 之后**不该再出现**，出现即 bug |
| `无候选步` | 模型答案里找不到承载该点的步 |
| `白名单外符号` | 步内符号不在白名单，L1/L2 都不可判 |
| `merged分摊` | 一步承载多点，部分对无处分摊（段 3 处理） |
| `无锚点` | equation 与 criterion 双空 |
| `规范未过` | 式子等价但结果规范不达标 |

**④ 数据缺陷豁免（2026-11-25 22:26 追加，来自 T32 §3 实测）。**

**当前 3 处 L1/L2 `fail`，0 处是模型错，全部是我们的数据缺陷**：

| 步 | L2 报的 | 真实归因 |
|---|---|---|
| `A-05-S11` | 加减项量纲不一致 | 一步焊了两条守恒式（动量 + 能量） |
| `A-06-S01` | 加减项量纲不一致 | 一步焊了三条（`f=μmg`、`a1=-μg`、`a2=μg`） |
| `B-07-S11` | 加减项量纲不一致 | `equation` 写成 `m*sqrt(v)`，`value.exact` 是 `m*v**2/4`（后者对） |

所以 `credit()` **不许直接吃 L1/L2 的 `fail` 判 miss**。必须先查 `判分器/defects_v1.json`：

> **23:17 补（T33 复核发现）**：只读 `items`（产物侧，8 条）。金标侧三条在 `gold_items`，其 `step_id` 与产物同号（`B-20-S05/S06/S10`），**不得用于判分豁免**——否则产物 S06 的真错会被金标缺陷吞掉。

- 命中 `merged_step` / `field_mismatch` / `no_slot` → 该步判 `na`，`na_by_reason` 记对应标签；
- **豁免只作用于 `fail`，不作用于 `pass`**（不许用它掩盖真判对）；
- 豁免必须落进产物，不许静默降级；
- 豁免表是**人工维护的数据文件**，判分器只读不算——因为自动判据区分不了「移项」和「焊两条」
  （实测：statement 多等号判据命中 35 处、多未知量判据命中 49 处，绝大多数是正常移项）。

> `na_by_reason` 因此要多两个键：`merged_step`、`field_mismatch`（`no_slot` 复用已有的 `白名单外符号`）。
> 这是对 §3.1③「不许新增标签」的**唯一例外**，理由：这两类不是"判不了"，是"数据错，不许算模型的账"，
> 混进 `白名单外符号` 会让 G4 校准看不出真实分布。

## 4. 段 2：S3 —— 等价形式与结构隐含

三件事，每件都带一条反例测试。**做完一件测一件，不许三件一起做完再测。**

### 4.1 等价形式识别

**要解决的**：同一个物理式子写成不同形式，L1 的 `eqsim` 认不出来。
**已知必过项**（T20 对齐裁定书 §三）：A-02 的三处，不做则 1:1 命中从 32 掉到 29。
**反例守卫**：**B-12-S03/S04 方程完全相同（`eqsim=1.0`）但不是同一个采分点**。
所以等价形式**只能解决「同一个点内部的形式差异」，不能用来合并两个点**。这条写反了会把 B-12 判错。

### 4.2 结构隐含判定

**要解决的**：模型用另一种结构表达了同一件事。三个已知形态：

| 形态 | 例子 |
|---|---|
| 两段式子求和表达「分两段」 | 模型写两段位移相加，金标写一段 |
| `v(nR) ≈ v(R)` 绑定两个符号 | 用近似绑定替代等式 |
| 折点坐标替代斜率截距 | 图读题常见 |

**反例守卫**：A-10-S06（人工 1:n，漏 S08 边界式）——**不能为了救它把 θ 降下来**，S2 报告 §3 已实测「降 θ 先吞进噪声」。

### 4.3 同名异义消歧

**要解决的**：同一个名字指不同量。**不是改名**——是同一个 `v1` 在两处指两个东西（A-08）。
**判据**：靠 `situation.given` + 段 0 的绑定表 + 碰撞守卫（裸名多义且无绑定 → `na`，**不判 `fail`**）。
**反例守卫**：A-09 的张力 `T` 撞周期 `T`——现在因为没守卫被判成 fail，段 2 必须让它变 `na`。
