## 1. 这张图长什么样（用来确认你找对了）

题干（原文见 `采分点/题干原文/B-20_2024山东_17.md`）：
> 质量为 M 的轨道静止在光滑水平面上……半圆部分半径 R＝0.4 m……
> 给轨道施加水平向左的推力 F，小物块处在轨道水平部分时，**轨道的加速度 a 与 F 对应关系如图乙所示**。

| 项 | 应有内容 |
|---|---|
| **图乙**（必须） | 纵轴 a、横轴 F 的**两段折线**。F ≤ 4 N 段斜率 **0.5 kg⁻¹**（= 1/(M+m)）；F > 4 N 段斜率 **1 kg⁻¹**（= 1/M），并在 F 轴上有截距（对应 −μmg/M = −2 m/s² 的横截距 F = 4 N） |
| **图甲**（顺带，有就一起要） | 轨道剖面：水平粗糙段 + 竖直光滑半圆段，P 点为连接处、Q 为最高点，小物块在水平段上 |
| **能看清的最低标准** | 两段折线的拐点、两个轴标签（a、F）与刻度数字可辨认。**不用高清，能读数就行** |
| 正确性校验值 | 该题答案 μ＝0.2、m＝1 kg、M＝1 kg、L＝4.5 m、v＝4 m/s。图乙拐点应在 **F=4 N** 处 |

## 4. 来源记录要写什么

`_来源记录.md` 每条一行：

```
| 文件名 | 来源站 | URL | 检索式 | 获取时间 | 与原卷一致性判断 |
```

- **URL 必须是能点开的原页面**，不是搜索结果页
- 拿到多份就都记上，并比对是否同一张图（若两张图折线形状不同 → 至少一张是重画的，标出来）
- 判断一致性时用 §1 的校验值（拐点在 F=4 N、两段斜率比 1:2）

## 5. 明令禁止（这几种做法等于伪造数据源）

| 禁止 | 为什么 |
|---|---|
| 用 AI 生成图 | 数据源必须是原卷，生成的图无法证明是原题 |
| 自己用 matplotlib/PIL 按答案重画 | 那是「用答案造题面」，违反最基本的方向性 |
| 拿相似题（同为板块模型的其它年份）的图顶替 | 题干条件不同，斜率截距就不同 |
| 裁掉坐标轴只留折线 | 轴标签和刻度是读数必需的，缺了等于没图 |
| 只存截图不存来源 | 无法复核，下一轮会被当成「来源不明」退回 |

## 6. 找不到怎么办（必须如实报）

按 §3 五条路径都试过仍找不到 → 写 `原始资料/题图/_未找到说明.md`：

```
试过：路径1（站名+检索式+结果：有/无）
     路径2 ...
结论：N 条路径均无图乙原图
旁证：找到的解析文章里图乙是重画的（依据：折线拐点不在 F=4N / 无轴刻度）
```

**不许因为找不到就随便交一张。** 交一张错的图，比交「没找到」危害大得多 —— 后面所有读数探针都会基于它，而且没人会怀疑。

## 7. 拿到图之后（附带的第二件事，能跑就跑）

工作区已有本地方案（llama.cpp + Qwen2.5-VL-3B，纯 CPU，零外部接口），启动脚本 `评测/scripts/read_figure.sh`。

跑一次读数探针，报回：

| 问题 | 真值 |
|---|---|
| 图中有几段折线？ | 2 段 |
| 两段的斜率之比？ | 1 : 2 |
| 折点对应的 F 是多少？ | 4 N |
| 纵轴标签是什么？ | a |

**已知失败模式**（上一轮合成图实测）：直接问「截距是多少」它会答错（答的是折点纵坐标，因为没做「延长到 F=0」这个动作）；改成「已知过两点求截距」就答对。
**所以两种问法都试一次，把两种结果都报回来** —— 这是在验「提示词要不要拆两步」，不是在验模型笨不笨。

读不准也如实报，**不许调参调到看起来对为止**。
