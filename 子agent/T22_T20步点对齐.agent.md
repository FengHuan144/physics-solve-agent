## 3. 方法（顺序不能反）

**每题先读模型产物，后读金标。** 理由：先读金标会被它的措辞锚定，容易把「模型写得跟金标不像」误判成「模型没做」。顺序是：

1. 读 `out/{q}_validated.json`，对每一步只写一句「它在算什么」，**不看金标**；
2. 再读 `schema/examples/{q}.json`，逐点找证据；
3. 判类（§5）、填 `home`；
4. 回到模型产物，把 `dup`/`new`/`meta` 的剩余步收尾；
5. 算 §10 的算术自洽。

## 5. 分类词表（不许自创类别）

### 5.1 模型步：`class` ∈ 5 类，互斥

| class | 定义 | 必填字段 |
|---|---|---|
| `primary` | 与某个金标点是**同一个可判事实**（判据见 §6） | `point_id`（单个） |
| `split` | 是某个金标点所涉内容的一部分，金标把它并在一步里、模型单独拆出来了 | `point_id`（单个） |
| `merged` | **一步同时承载 ≥2 个金标点**，且模型没给它们分开的式子/判断（真合并） | `point_ids`（数组，≥2） |
| `dup` | 与**本题另一模型步**同义：同一式子换形、同一句话说两遍 | `dup_of` |
| `new` | 金标没有的**独立可判事实**（真多出来的物理动作，不是重复） | `note`（写清这个事实是什么） |
| `meta` | 不含独立可判事实：过程声明、结论复述、自我检查、单位换算 | — |

**`split` 与 `dup` 的分界**：删掉这一步，金标那个点的证据链**少一块**→ `split`；**一点不少**→ `dup`。

**`merged` 为什么单列**：步数比 >1 说明总体是拆，但**单点合并**仍可能局部存在（模型一步里既列了动量式又列了能量式）。合并会让「部分对」无处分摊——这是判分器唯一真怕的形态，必须能报出来。若某题 `merged` 数为 0，明确写 0，不要省这一行。

### 5.2 金标点：`home` ∈ 4 类

| home | 条件 | 判分含义 |
|---|---|---|
| `1:1` | 只有一个承载步，且该步是 `primary` | 最理想，直接一对一判 |
| `1:n` | 承载步 ≥2（`primary` + 若干 `split`，或纯 `split`） | 可以判，但要按点聚合、不能按步扣 |
| `merged` | 只被某个 `merged` 步承载，**没有独立步** | **部分对无处分摊**，这是判分器唯一真怕的形态 |
| `none` | 模型产物里找不到证据（`closest` + `gap` 必填） | 要么金标点不可判，要么模型没写 |

## 6. 「同一可判事实」的操作判据

**算同一**（任一条成立）：

1. 金标点有 `value.number`，模型产物出现**同物理量、同数值**（相对容差 1e-6）。符号名不同算同一，但要记进 `alias`。
2. 金标点有 `equation`，模型式子与它是**代数等价**（移项、代入已知常量、两边同除）。允许符号重命名，须在 `alias` 列出对照。
3. 金标点是 `judgment`，模型有对应的方向/条件判断句，且**判的是同一件事**（不是同一个词）。

**不算同一**（反例，出现即按错判处理）：

- **数值巧合**：`4` 同时出现在 `4 N` 与 `4 m/s` 里，不算。
- **同式不同物**：同一个公式用在另一个物体/另一段过程上，不算。
- **只沾词**：金标说「机械能守恒」，模型只是提到「守恒」二字，不算。
- **方向相反**：数值同、符号相反（`-5` vs `5`），**不算同一但在 note 里必须写清差在正负号**——这可能是个真错，不许悄悄抹平。

|---|---|---|
| A-08-S06 | `a2`=5.0 m/s² | `A-08-S08`/`S12` 正文写「加速度为 -μg=-5 m/s²」，**同时符号相反 + 未结构化为 value** |

## 10. 验收（脚本必须能核，不是自我感觉）

写进 `_build_t20align.py`，任一不满足就退出码非 0：

1. **覆盖**：101 个 `step_id` 一个不少、无重复；66 个 `point_id` 一个不少。
2. **算术自洽（每题 + 合计）**：
   - `model_steps = Σclass(primary) + Σ(split) + Σ(merged) + Σ(dup) + Σ(new) + Σ(meta)`
   - `gold_steps = 计数(home=1:1) + 计数(home=1:n) + 计数(home=merged) + 计数(home=none)`
   - `merged` 步必须撑起 ≥2 个 `home=merged` 的点（否则是判错）
3. **必填**：`primary`/`split` 的 `point_id` 必须存在于该题金标；`merged` 的 `point_ids` 至少 2 个且全部存在、不得重复；`dup` 的 `dup_of` 必须存在且不等于自身。
4. **证据逐字**：每条 `evidence` 必须是该步 `statement` 的子串（`in` 断言，不做模糊匹配）。
5. **`none` 有交代**：`none` 点必须同时有 `closest` 与 `gap` 非空。
6. **`new` 有内容**：`new` 步的 note 必须写出「多出来的那个事实」是什么，不能写「模型多写了一步」。

人工抽检：T00 会随机抽 10 条复核 `class` 判定，**错 1 条以上整卡退回**。

## 11. 必须回答的三个结论（写进说明 md 首屏）

1. **补点候选几个？各值几分？**（`new` 步汇总）—— 这决定金标要不要改表。改表是**另一张卡**，本卡只提候选、不裁。
2. **冗余率多少？** = `(dup + meta) / 101` —— 决定判分器对「学生多写」的容忍度：若冗余率高，说明多写不扣分是常态；若极低，说明模型的每一步都在做事，判分器不该轻易放过「写多了」。
3. **point-centric 判分可行不可行？** 66 个点里：`1:1` 几个、`1:n` 几个、**`merged` 几个**、`none` 几个。`merged` 和 `none` 要逐个说明——`merged` 是「部分对无处分摊」，`none` 要分成两种：**点本身不可判**（如「规范作答」类）还是**模型没写**。前者改点，后者是模型的问题，性质不同，必须分开报。

## 12. 出错怎么报

- 发现金标点与采分点表**原文不一致**（不是理解不一致，是字面不同）→ 单列「不一致清单」，附两处原文，**不自行改**。
- 发现模型产物**自相矛盾**（同一式子前后不同）→ 记在 note，算 `new` 还是 `dup` 照 §5 走，但在说明里单列。
- 发现本卡的判据**覆盖不了某个实际情况** → 写进说明最后一节「卡面缺口」，附具体 step_id。**不许自己发明新类别填进去。**
