## 2. 修 P0-D：恒等式方程被 L1 判 pass

| 项 | 内容 |
|---|---|
| 现象 | `equation.sympy = "0"`（或 `x-x`）→ L1 `pass`、L2 `na`，**同一输入两层打架** |
| 后果 | 上游给一个空方程，L1 认「这步算对了」→ 是可绕过的通过 |
| 根因 | `l1_deduce.py` 的 `prepare()` 解析后没有「化简为 0」判断，`per_step`/`chain` 都把残差 0 当自洽 |
| 已有可复用件 | `l1_deduce.py:84` 已有 `_is_zero(expr)`；`l2_dimension.py:60` 有同类判断 |

**做法**：解析成功、两种模式消费之前，若 `_is_zero(rec.expr)` 为真 → 该步 L1 记 `na`，detail 与 L2 措辞对齐（「方程化简为 0，无可比两侧」）。可以用 `rec.skip_kind` 机制，但**结果必须是 `na`，不是 `skipped`**。

**不许**：判 `fail` / 给 `E-10`。空方程不是算错，是没有判定对象，按 `schema/字段清单.md` §0 欠定应判 `na`。

## 3. 修 P0-C：非 SI 单位 100 倍差两层全过（**按方案 ① 实施，口径已定**）

### 3.1 裁定原文

> 用户 2026-11-25 14:05：「2 选 1」。
> 方案 ①：**L1 读 value 时按 `unit` 换算成 SI 再入已知量。** L2 仍然只比量纲（不改 L2 职责）。

### 3.2 现状（三条读法都绕开了单位）

| 位置 | 代码 | 问题 |
|---|---|---|
| `l1_deduce.py:~172` | `v = g.get("value")` → `float(v)` | 题干 `given[]` 有 `value` 与 `unit` 两个字段，**只读 value** |
| `l1_deduce.py:~243` | `num = val.get("number")` | 步级 `value.number` + `value.unit`，**只读 number** |
| `l1_deduce.py:~255/355/387` | 同上 | 三处再读一遍，漏改一处就留一个洞 |

`value.unit` 走 Schema pattern `^[A-Za-z0-9/^*.·-]+$`，`cm/s^2` 完全合法，Schema 拦不住。

### 3.3 做法（指定）

**不要逐个改调用点**——一共 5 处读 `number`/`value`，改漏一处就前功尽弃。做**一个统一入口**：

```
在 l1_deduce.py（或 units.py，你定）新增：
    def to_si(number, unit, symbol=None) -> float
规则：
  1. unit 为空 / None / "1" / "-"            → 原值返回（无量纲量，如 μ、n）
  2. unit 能被 pint 解析（含词头：cm/mm/km/g/mg/kJ…）→ ureg.Quantity(number, unit).to_base_units().magnitude
  3. unit 是白名单「单位_SI」列里的写法        → 同上（白名单是唯一准入名单，units.py 已有 unit_map()）
  4. unit 解析失败                            → 抛 DataError，**不许静默当 SI**
```

然后把上面 5 处读值**全部改走 `to_si()`**。改完 `grep -n "get(\"number\")\|get('number')" 验证器/l1_deduce.py` 应该只剩 `to_si` 内部的实现，其余都是调用。

### 3.4 三个坑（踩了会被抓）

| 坑 | 说明 |
|---|---|
| **不许改 L2** | L2 职责是量纲，`cm/s²` 与 `m/s²` 同量纲本来就该 pass。补单位换算不是 L2 的活 |
| **不许回写 JSON** | 换算是判分时的临时视图。写回样例等于篡改金标，且会让 7 份哈希全变 |
| **`exact` 字段不参与** | `value.exact` 是 sympy 串（如 `sqrt(2*g*R)`），里面的 `g` 是符号不是单位，**不要拿它做换算** |

### 3.5 转换后必须验证的一件事

7 份样例全是 SI 单位（`m`、`m/s`、`kg`、`N`、`J`、`s`、`m/s^2`）。**换算对它们必须是恒等变换** —— 也就是说：

```bash
# 逐份跑，validation.layers 必须一字不变
for f in schema/examples/*.json; do python schema/validate_schema.py "$f"; done
```

若任何一份的 `L1`/`L2` 从 `pass` 变成别的 → **你的 `to_si()` 有 bug**，回去查，不许把样例改动当「新发现」。
