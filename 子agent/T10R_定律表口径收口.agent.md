## 1. 第一件：12 条定律的内容复核（本卡的主任务）

```bash
cd "D:/峤的个人档案/做点东西/物理解题agent"
python -c "
import csv
for r in csv.DictReader(open('知识表/定律适用条件_v1.csv',encoding='utf-8-sig')):
    print('='*70); print(r['law_id'], r['定律名称'])
    for k,v in r.items():
        if k not in ('law_id','定律名称'): print(' -',k,':',v)
"
```

**逐条判四件事，每条都要写判断与依据**：

| # | 判什么 | 判错会怎样 |
|---|---|---|
| 1 | **成立条件**是否覆盖该定律的必要前提（漏了哪条） | L2/L4 会用不成立的定律判「通过」 |
| 2 | **否定式条件**（「若…则不能用」）是否真的是失效边界，而不是同义重复 | 写「若不满足成立条件则不能用」等于没写 |
| 3 | **不成立时的替代**是否指向真的可替代的方法 | 指错了等于把人引到更错的路 |
| 4 | **典型误用**是否真在 27 题里出现过，还是编的 | 编的误用会把「高频错误」讲成假的 |

**判定纪律**：第 4 条尤其要守。凡标着「典型误用」的，去 27 题原文与采分点里找对应证据；找不到就写「未在 27 题中出现，属通用误用」——**别让「典型」这个词白拿**。

## 2. 第二件：P1-1 —— 「关联公式」列到底是索引还是白名单

### 现象

12/12 条定律都只引「核心式」，平均 3.7 条，而各定律自有 2~10 条。口径缺失的源头在 `子agent/T10_定律适用条件表.agent.md:65`：只写「T09 的 formula_id」，**没规定穷举或精选**。

### 为什么这不是小事

| 若这列是「索引」 | 若这列是「白名单」 |
|---|---|
| L2 用它做检索入口，允许取库内其他式子 | L2 **只能**用列出的式子 |
| 漏引不影响正确性，只影响召回 | 漏引 = 该定律直接不可用 → **会误杀正确答案** |
| 现在的 3.7 条平均够用 | 现在的填法会让 L-01 少 6 条可用式，L-03 少 5 条 |

`t10独立审查.md` §4 P1-1 的警告是后一种：**补成穷举可能把白名单放大到「任何题都能用任何式子」**。

### 你要交的不是结论，是账

出一张 12 行 × 4 列的表：

| 定律 | 现引（条） | 自有（条） | 未引清单 + 每条一句「为什么没引」 |
|---|---|---|---|

「为什么没引」只有三种合法答案：

- **甲 该引而漏了**（核心式的直接推论，读者大概率会用到）
- **乙 不该引**（成立条件与该定律正交，引进来会扩大适用范围）
- **丙 引了会冲突**（与另一条定律的适用条件互斥，同时列出会让 L2 选错）

**甲类是要补的，乙丙类是要写清理由的。** 补之前先看 `T09R` 卡的进度——它在改公式库，你补引用的 id 可能变。

### 口径建议（你可以提，但不能定）

据这张账给一个建议：这列该按「索引」还是「白名单」用，以及两种用法下 12 条各自该怎么填。**最终由用户裁定**——因为这决定 L2 的误杀率与放行率，属口径层。

## 3. 第三件：P1-2 —— 5 条跨定律引用没有前提标注

### 现状（`check_laws.py` 已报出，退出码 0 + 1 项 WARN）

```
5 条跨定律引用（须人工确认是否联立必需）：
L-05→F-022、L-07→F-031、L-09→F-042、L-10→F-043、L-11→F-067
```

### 问题不是「引错了」，是「读不出前提」

`t10独立审查.md` §4 P1-2 举的例子最清楚：

> L2 若按白名单取式，可以合法地写出 `GMm/r² = mv²/r`，但 F-031 的适用条件「合外力指向圆心」不会被单独检查——**椭圆轨道题上会直接套错，且不报错**。

### 逐条要交的东西

| 项 | 要求 |
|---|---|
| 为什么必须联立 | 一句话，说明这条式子单独拿出来为什么不够 |
| 成立前提 | 一句话，写清「在什么条件下这条引用才合法」 |
| 反例 | 一个「前提不成立时套用会错」的具体场景（能对应到 27 题里的某题更好） |

### 两种标记格式的代价（只评估，不实现）

| 格式 | 做法 | 代价 |
|---|---|---|
| **①** | 在 `关联公式` 里标跨定律项，如 `F-031@L-06` | 不动列结构；但解析要改，`check_laws.py` 与将来的 L2 都要认这个语法 |
| **②** | 新增一列 `跨定律引用条件` | 语义最清楚；但改表结构，`check_laws.py` 的必填校验要跟着改 |

`t10独立审查.md` 说「二者都属 schema 变更，建议由 T08 裁定」。**所以你的交付是评估，不是选型。**
