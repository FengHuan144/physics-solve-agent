## 4. 与卡的偏差（3 条，都不动语义）

1. **产物顶层多了两个字段**：`grader_version`（本阶段 `"t25-s1"`）与 `na_reasons`（本阶段 `{"未实现": n}`）。理由：D1 的 C 形态要求 `na` 按原因分列，先把枚举和校验位埋好，S2 起直接填。`points[]` 四要素与 `summary` 字段**一个没动**。
2. **`hit_rate` 在 `hit+miss=0` 时写 `null`**。卡原话「算不出就别给」；`null` 是不给，不是 0。
3. **S1 的 `score_range` 写 `[0, 分值]`，不是 `[0,0]`**。`na` 的含义是「判不了」，不是「该点该得 0 分」；区间上限保留该点满分，避免把我们的盲区写成学生的 0。`score` 仍严格为 0。
