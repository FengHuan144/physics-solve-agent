## 2. 段 B1：15 个白名单外符号 → 走别名绑定（可直接做）

### 2.0 前置：`alias` 是**单向**的，改绑定前必须先懂这条

`验证器/alias.py` 的作用是「把**模型侧**符号归一成**金标侧**符号」。它只能朝这一个方向用。

**拿它去跑金标 = 自我改写。** 00:05 实测：金标 `A-08` 开 `alias=True` 后 L1 从 `74 pass / 0 fail` 变成 `70 pass / 4 fail`，四处假 fail 全在 `A-08-S01/S02/S08/S09`。根因是绑定表第 19 行那条（原文自己写着「最可能判错的一条」）：

```
A-08, v1, v2b, bind, ... 模型在 S11 把 v1 复用为 b 的冲量后速度
```

金标的 `v1` 本来是**物体 1 的速度 6 m/s**（S01），被改写成 `v2b`（b 的冲量后速度 2 m/s，S08）→ 同一个槽 `v2b` 在题内装了 6 和 2 两个值 → 冲突 → 假 fail。

**所以：**
1. **验证只许用这两个组合**——金标 `alias=False`、产物 `alias=True`。**永远不要用「金标 + alias=True」当基准**，那个数没有意义。
2. **新增/修改绑定必须做槽位碰撞检查**：改完后用 `判分器.grader.slot_collisions(doc)` 对 20 份产物逐个跑，`slot_collisions` 的槽位数**不许增加**（当前只有 `A-05` 的 `M`，`4*m` 与 `m/9`）。
3. **`A-08` 的 `v1→v2b` 这条绑定，段 B1 若判定要动，必须单独写一节复核**，不许顺手改。它是全表风险最高的一条。


### 2.1 为什么是「绑定」不是「加白名单」

`验证器/alias.py` 的设计前提（T23 已写死）：**不许词法归一**。直接往 `符号白名单_v1.csv` 加 `v_y`，会让它通过白名单检查但**没有物理语义**（不知道它是竖直速度还是别的），L2 量纲仍然判不了。

正确做法：在 `知识表/别名绑定_v1.csv` 里把每个符号**绑到一个已有槽位**（该槽位有量纲、有物理定义）。只有当确实找不到对应槽位时才新增槽位，新增要写清物理量与量纲。

### 2.2 逐个判，一个都不许跳

| 符号 | 你要判 | 依据从哪来 |
|---|---|---|
| `v0min` | 是最小初速？绑 `v` 还是新增 `v_min`？ | `A-09` 金标该步 statement |
| `v_y` | 竖直分速 → 绑 `vy`（若已有）或新增 | `B-05` 金标 |
| `t_e` | 末段时间 → 绑 `t` 还是新增 | `A-08` 金标 |
| `s_e` | 末段位移 → 绑 `s` 还是新增 | `A-08` 金标 |
| `W_T` | 总功 → 绑 `W` 还是新增 | `B-04` 金标 |
| `V_P` | 势能 → 是否就是 `Ep`？ | `B-20` 金标 |
| `v50` / `v30` | 下标是"第 5 秒/第 3 秒"还是别的？ | `A-01` 金标 |
| `Ebar` | 平均能量？ | `A-01` 金标 |
| `Vn1` | ？ | `A-03` 金标 |
| `v_R` / `v_n` | 半径 R 处 / nR 处速率 → 都可绑 `v`？ | `A-10` 金标 |
| `v12` | 1→2 过程的速度？ | `B-01` 金标 |
| `v_x` | 水平分速 → 绑 `vx`？ | `B-05` 金标 |
| `u_rel` | 相对速度？ | `B-20` 金标 |

**每个符号必须给三样：绑到哪个槽（或新增）/ 依据的原句 / 绑不上的理由。** 绑不上的就写「不绑」，**不许硬凑**。
