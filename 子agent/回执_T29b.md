## 5. 发现的代码/数据问题（只报不改）

1. **D5 的扫描方法有盲点：扫不出「字面撞白名单、语义是另一个量」的符号。** 本批两条（`T`=绳张力、`P`=绳拉力）都不是"未知符号"，而是命中了 T=周期、P=功率。这类错在 L2 上直接表现为 E-12 假阳性，扫描（只找不在白名单的标识符）永远发现不了。建议后续加一步：**值单位与白名单量纲不符**的步，人工过一遍。
2. **B-02 的 `vBx` 与 `v_B` 是同一个量的分量/大小两种写法**，模型自己在 S05 用 vBx（−2v）、S06 用 v_B（2v）。这种"同题两写法"如果分到两个 id 会把一个量拆成两个；本批靠"同量异名共槽"绕过去了，但根本上该由生成侧统一。
3. **合并式（两条定律写成一个 sympy 串）在 L2 上只有一半能抓到**：A-05-S11、A-06-S01 因为动量与能量量纲不同被抓到；B-01-S02（两条同量纲式子相加）抓不到。建议另立卡处理"一个式子一条定律"的解析约束。
4. **A-09 的 `l`（绳长 1.5 m）与 `L`（钉距 0.5 m）同题并存且含义不同**——正是白名单 L 行风险提示里说的"禁止映射"情形，本批按 d 处理，未动 L。
