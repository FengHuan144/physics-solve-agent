## 5. 发现的代码/数据问题（只报不改）

1. **A-06 的 `given` 缺 μ**。题给「动摩擦因数 μ＝0.3」、g＝10，但 given 只有 `l/m/g` 三条。后果：S06（v_b=μg t1）的 L1 永远 na，即使符号已绑对。属产物数据缺口。
2. **A-01/A-03/A-05 的 value 全是 `exact` 符号式、`number` 为空**。这三题的 L1 判定率恒为 0，与符号无关。若希望 L1 对符号题也能判，需要生成侧把可数值化的量写成 `number`（或 L1 支持符号比对）——是独立议题。
3. **A-06-S01 与 A-05-S11 是同一类错**：模型把两条定律（或力与加速度）塞进一个 sympy 串。这类"合并式"在 L2 一定 E-12。若判分口径认为"合并写也该给分"，需要在生成侧提示词里禁止，或让 L2 支持多式；目前按"一个式子必须量纲自洽"处理是对的。
4. **`d`（A-03）在白名单里是「一段直线段的长度」，模型拿它当随时间变的间距变量（`d - v0*t + 1/2*g*t**2`）**。量纲都是 m，L2 判 pass，语义上有偏差。本轮未动（它不是未知符号，是身份映射）。
5. **A-03 的 `v0` 与金标 `v1` 是同一个量**（金标 S01 写 v₁²=2gl，模型写 v0=√(2gl)）。本轮**没有**把 v0 重绑成 v1：v0＝初速度在题内自洽，重绑收益为零、风险非零。记录在此供你判定是否要"跟金标改名"。
