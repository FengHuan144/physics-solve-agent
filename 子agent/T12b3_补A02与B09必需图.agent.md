## 1. 这两张图长什么样（用来确认你找对了）

### 1.1 A-02 · 2022 全国乙卷 25 题 · 图 (b)

一张 **v-t 图**（速度—时间图）：

| 要核的特征 | 具体是什么 |
|---|---|
| 横轴 | 时间 `t`，刻度标注应为 `t₀`、`2t₀`（可能还有 `0`） |
| 纵轴 | 速度 `v`，刻度标注应为 `v₀` 与 `1.2v₀`（或以 `v₀` 为单位） |
| 曲线 | **两条**：一条从 `1.2v₀` 出发**下降**、一条从 0 出发**上升**，在 `t = t₀` 处相交（相切，共速 `v₀`），之后继续分开 |
| 终点 | 在 `t = 2t₀` 处，上升那条到 `2v₀`，下降那条到 `0.8v₀` |
| 图注 | 原卷无图题（不要因为有「图(b)」字样就找错） |

**判对的关键**：图上必须能读出 **`1.2v₀`、`v₀`、`2v₀`、`0.8v₀` 这四个速度值**。如果一个都读不出来，就是找错图了。

> 原题题干（原文照录）：`A、B 的 v-t 图像如图（b）所示`。原卷同时还有「图（a）」是装置示意图（A 与弹簧连接、B 向 A 运动），**图（a）不是解题必需**（题干文字已说清），**本卡只要图（b）**。

### 1.2 B-09 · 2021 广东卷 13 题 · 图1

一张**算盘示意图**（侧视或俯视的导杆 + 算珠）：

| 要核的特征 | 具体是什么 |
|---|---|
| 主体 | 一根**水平导杆**，杆上**两颗算珠**（标 `甲`、`乙`） |
| 关键标注 | **两个边框**：`a` 和 `b`。原文说「甲靠边框 b」「乙与边框 a 相隔 s₂」→ 说明 **a 与 b 在杆的两端** |
| 相对位置 | 甲靠 `b`；乙在甲的另一侧；`a` 在最远端 |
| 距离标注 | 图上可能标 `s₁`、`s₂`，也可能不标（原文已给数值，图上不标也算对） |
| 图注 | 原卷无图题 |

**判对的关键**：图上必须能看出 **`a` 和 `b` 分别在哪一端**。如果图上只有一个边框或没有边框标注，就是找错图或图太糊。

> 原题题干（原文照录）：`如图所示，水平放置的算盘中有甲、乙两颗算珠未在归零位置，甲靠边框 b，甲、乙相隔 s₁＝3.5×10⁻² m，乙与边框 a 相隔 s₂＝2.0×10⁻² m`

## 5. 明令禁止（这几种做法等于伪造数据源）

1. **不许用 AI 生成图**（包括任何文生图工具）。
2. **不许按题干和答案自己重画**。你画得再准，也不是原卷——而这两张图后面会被当成「学生看到的东西」用于评测。
3. **不许拿相似题的图顶替**。v-t 图长得都像，但读数不同就是不同的题。
4. **不许把读不出的图交上来充数**（糊到看不出 `1.2v₀` 的 A-02 图等于没图）。
5. **不许抹水印**。抹了就没有可核对的痕迹了，等于改数据源。
6. **不许改 `原型/_build.py`**。命名按本卡 §2 来，不需要改代码。

## 6. 找不到怎么办（必须如实报）

**交「没找到」比交一张错图好得多**，因为错图没人会怀疑。

以下情况都算合法的交付：

| 情况 | 报告怎么写 |
|---|---|
| 找到图但读不出关键读数 | 交图 + 写明「读不出 X，疑裁切不全/分辨率不足」，**并说明它不能用于解题** |
| 只找到重绘版 | 交图 + 标「疑重绘，与 §1 特征表有 N 处不符：…」 |
| 一源都没找到 | 写「试过的 N 条路径 + 每条的结果」，不许写「网上没有」这种结论 |
| 两源互相矛盾 | 两个都交，列出差异，**不要自己选一个** |
