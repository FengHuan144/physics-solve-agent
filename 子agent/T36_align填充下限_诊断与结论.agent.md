## 1. 改了什么

`判分器/align.py`：

```python
FILL_MIN = 0.0     # 新增模块级常量

def map_steps(..., fill_min: float | None = None):   # 新增参数
    if fill_min is None:
        fill_min = FILL_MIN
    ...
    if fill and not idx and mids:
        t = max(range(len(mids)), key=lambda k: sim[i][k])
        if sim[i][t] >= fill_min:      # 新增这一层判断
            idx = [t]
```

原行为：DP 之后仍为空的点，**无条件**取相似度最高的模型步——相似度 0.03 也照填。
新行为：只有该相似度 `>= FILL_MIN` 才填。`FILL_MIN = 0.0` 时与原行为**完全等价**（相似度恒 ≥ 0）。

备份：`判分器/align_备份_20261126_1400_T36改fill前.py`

## 4. 结论：甲方案无效

**`A-09-S02`、`A-09-S03`、`A-09-S09` 在全部 11 档阈值下都是 hit。**

它们不是 fill 硬塞的，是 DP 在 `sim > THETA(0.12)` 时正经配上的。改 fill 只能杀 `B-04-S04`（sim=0.129，唯一一个真·兜底步），代价是同时掉真 hit `B-07-S03`（sim=0.163）。**净收益为负。**

真正的原因在下一层（见 `临时/t36/hit_basis.py`）：67 个 hit 里 **53 个（79%）靠「L1/L2 全 pass」拿到**，根本没比对金标式子；`A-09-S02` 产物 `v0²−v²−2gL` 漏了 m（值 90 vs 正确 80），但本步量纲自洽、能推出，L1/L2 全 pass → 直接 hit。

- **不使用**（`FILL_MIN` 恒 0.0）：段 1 口径不变，20 份产物不动。
