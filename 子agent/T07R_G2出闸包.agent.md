## 2. 第二件：G2 出闸到底缺什么

`任务进程.md` 的 G2 出闸条件：**「裸模型基线准确率 + 失败分布」**。逐项对：

| 出闸要求 | 报告里有吗 | 缺什么 |
|---|---|---|
| 准确率 | ✅ 三个变体 90.9% / 95.5% / 86.4% | **分母口径要说清**：22/29 而不是 27/27 |
| 失败分布 | ✅ §6 有 | 失败类型是否按 21 条错误码归过？（若没有，如实写「按现象归，未按错误码归」） |
| 复现 | ✅ §11 有命令 | 复现命令要能**一键跑通**，不是罗列 |
| 样本覆盖 | ⚠️ 22/29 | **缺一份「哪 7 题没跑、为什么」的清单** |
| 口径裁定 | ⚠️ §9 | #1/#3 待定 → 并列，不选 |

**本卡的核心产出就是这张表填满**，尤其是「哪 7 题没跑」。

### 哪几题没跑，要说清

27 题实题里跑了 22 题，缺的应是 A-01~A-05（无题干原文）。**其中 A-05 已于 10:55 补到原文**，所以它现在是「有条件跑但没跑」，与 A-01~A-04 的「无原文不能跑」不是一回事——**这两种要分开写**。

先自己核一遍，别抄这句话：

```bash
python - <<'PY'
import sys, json, glob, os
sys.path.insert(0,'采分点/scripts')
from validate_points import load
rows=load('原始资料/五卷力学大题_采分点总表_v2.xlsx')
allq=sorted({r['point_id'][:4] for r in rows})
ran=sorted({os.path.basename(p)[:4] for p in glob.glob('评测/基线/raw/v3/*.json')})
print('全表', len(allq), allq)
print('跑了', len(ran), ran)
print('没跑', sorted(set(allq)-set(ran)))
PY
```

把这个差集写进报告。**如果差集不是 A-01~A-05，说明台账还有第三个说法**——那更要写清。
