## 3. 每一条绑定的判定流程（照做，不许跳步）

对每个 `(qid, model_symbol)`：

1. **定位**：在哪几步出现？`grep -n "v_P" 评测/T20/out/<qid>.json`
2. **读题干**：这个符号在题里指什么？原文怎么说的？（`原始资料/` 或 `选题落地_v4.md`）
3. **对金标**：金标同一步用的是哪个 `symbol_id`？同值吗？同单位吗？
4. **写 basis**：一句话说清「凭什么认定它等于这个 id」，要能被人复核。
   **不许写「语义相近」「显然」**——这种等于没写。
5. **写 evidence_step**：金标或模型里能佐证的那一步，形如 `A-01-S05`。
6. **填 risk**：这条最可能错在哪？（`v_b`→`v2p` 那条就是范例：明写「不能按词法归一成 vb」）

### 三种特殊情况

| 情况 | 做法 |
|---|---|
| 一个写法在本卷指两个不同的量（如 `s` 前 3 步指位移、后 2 步指路程） | **不许绑**。写成 `map_type=reserved` 不合适，直接留空、进「未决」，并说明分裂在哪几步 |
| 目标 id 在本题已被另一个符号占用 | 先判「是不是同一个量」。是 → 两条都绑到同一 id，在 risk 里写「同量异名」；不是 → **不许绑** |
| 模型写的是 sympy 保留名（`N` `I` `Q` `E` `beta`） | 若白名单有对应 id（`Nf` `Iimp` `Qheat` `Icur`）且语义吻合 → 可以绑；否则留空并标「生成侧 bug」 |

## 3.5 样板：A-04 已实做完（照这个标准写）

产物 `评测/T20/out/A-04.json`，9 步，**最终绑 6 条，L2 全部可判**。

| 模型符号 | 判定 | 依据 |
|---|---|---|
| `x1` | → `s1`（借槽位） | S03 `x1 - 1/2*a*t1**2`；x1 是 0~t1 加速段位移。白名单无「分段位移」槽位，借 s1 |
| `s` | → `s2`（借槽位） | S07 `s - v*(T-t1)`；s 是 t1 之后的匀速段位移，与 x1 拼成总位移 x |
| `v_s` / `vs` | → `vsnd` | 声速 340 m/s。**21:32 用户授权新增 `vsnd` 槽位**——原来 `v` 被车速占、`v0` 被「原文把声速记作 v₀」这句挤住 |
| `T` | → `tinst` | 「停止鸣笛的时刻」。白名单 `T`＝周期，同名异义；**21:32 同时新增 `tinst`** |
| `vi` | → `v0` | 初速度 0。声速挪到 `vsnd` 之后 `v0` 才空出来 |

**这里有个转折，必须看懂**：第一版判定是「2 条可绑、3 条必须留白」，理由是白名单没有声速/时刻槽位。
加上两个槽位后，三条留白**全部变成可绑**。

> **一个槽位卡住两条**：声速从 `v0` 挪走 → `v0` 空出来 → `vi` 才绑得上。
> 所以遇到「白名单没有合适槽位」，正确动作是**报上来等裁定**，不是硬借、也不是直接留白了事。

**结果**：L2 `pass 4 / na 5` → **`pass 9 / na 0`**，未识别 0 处、撞车 0 处、契约 0 违约。
L1 只从 `4 pass / 5 na` 涨到 `5 pass / 4 na`——原因见下面这条，非常重要。

> **L1 的 na 主因不是符号，是「本步没有 value」。**
> 绑完之后 A-04 剩下 4 步 na：2 步理由是「方程能解出 s1，但本步没给值」，
> 2 步是「3 未知 / 1 方程，要等全题联立」。这跟符号一点关系都没有。
> 所以**绑符号救的是 L2，不是 L1**。谁在回执里写「绑完 L1 覆盖率上升」，要拿数据说话。

### 由此得出的三条判据（写进每一批的回执）

1. **有合适槽位 → 直接绑**，risk 写「为什么是它」。
2. **没槽位但能借 → 借**，risk 必须写「借的是谁的槽位、字面语义差在哪」。
   `A-08,s_rel,ds` 已有先例（明写「绑定的是一类量、不是同一个数」）。
3. **没槽位且借不了（原文级同名异义）→ 报上来等裁定。**
   A-04 原文「声速 v₀＝340」与白名单「v0＝初速度」正面撞车，这类情况**绑哪个都是错的**，
   但**也不许默默留白**——要写进回执的「未决」，说明「需要新增槽位 / 需要用户裁定」。
   默默留白会让下一个人以为这题已经处理完了。
