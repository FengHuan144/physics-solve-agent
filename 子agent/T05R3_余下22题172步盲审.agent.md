## 3. 判定方法：三步对

对每一步，按顺序做三件事：

### 第一步 · 存在性（这步该不该有）

在 §6 标准答案原文里找：**这个式子或判断，原卷答案/原卷解析有没有用到？**

| 情况 | 判 |
|---|---|
| 原卷答案里明确写了这个式子/这个判断 | **有依据** |
| 原卷答案跳过了（比如直接给结果），但要得到那个结果**绕不开**这个式子 | **有依据**（间接） |
| 原卷答案用的是完全不同的解法，本步属于「另一种解法」 | **有依据但需标注**：写「替代解法，本步在原卷解法中不出现」 |
| 原卷答案压根不需要，且不属于替代解法 | **无依据** ← 这是最严重的一类 |
| 原文里查不到对应内容（原文不全） | **无法判定**，单列，不要硬判 |

> 「替代解法」这条很常见，别把它判成「无依据」。物理题一题多解，一张表只能收一种。

### 第二步 · 分值（这个分合不合理）

先看规范 §3 的分值初值表，再看这道题的总分：

| 检查 | 判据 |
|---|---|
| 本步分值与规范初值是否一致 | 不一致要写清楚「规范初值 X，表内 Y，理由…」 |
| **本题采分点总分是否等于卷面分** | **必须等于。** 这是硬约束，T00 已核过 22 题全部闭合 |
| ② 类（原始方程）分值占比是否 ≥30% | 规范硬要求。低于 30% 就报 |
| 单步分值是否 ≥0.5 | 规范允许 0.5 起，低于 0.5 报 |

**⚠️ 最重要的一条**：如果你觉得「某步分值偏低应该加」，**不要直接判「应改为 X 分」**，因为**总分已经等于卷面分，加分必然要减别处的分**。正确写法是：

> 「S__ 分值偏低（现 X 分，按规范应为 Y 分），但本题总分已闭合于 Z 分，加分须同时指出从哪一步减，否则破坏闭合。」

前序就出过这个事：A-03 那题有人要加分，一算加完变 21 分，和卷面 20 分对不上，等于伪造配平。

### 第三步 · 口径（是不是照原卷写的）

口径 = 「什么情况给分、什么情况不给分」那句话。

| 情况 | 判 |
|---|---|
| 原文有口径，表内照录或同义 | **照录** |
| 原文有口径，表内**写得更严**（原文说「也可以」，表内说「必须」） | **改严** ← 违反 C15，要报 |
| 原文有口径，表内**写得更松** | **改松** ← 也报 |
| 原文该处为空，表内自己写了口径 | **自撰**，应标「口径C级：自撰」。若没标，报 |

**判据只有一条：表里那句话，能不能在原卷/讲义原文里找到对应。** 找不到就是自撰，自撰本身不错（总得有人写），但**必须标明是自撰**。
