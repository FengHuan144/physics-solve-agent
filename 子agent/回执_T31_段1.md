## 9. 对 §8.4「下一步」的更正（23:59，实测推翻，保留原文不改）

§8.4 写「修 Ⅰ+Ⅱ 的一个判据就能救回」，**这句话是错的**。我按两种候选判据逐点实测，结果如下（`_step_status` 口径：`fail` 优先，全 `pass` 才 `pass`，否则 `na`）：

|---|---|---|---|---|
| A-02-S09 | na×6 | **na,na,na** | ✗ | ✗ |
| A-02-S13 | na×2 | **na,na** | ✗ | ✗ |
| A-08-S11 | na×2 | **na,na** | ✗ | ✗ |
| A-10-S06 | na×1 | （无锚点步） | ✗ | ✗ |
| A-10-S07 | na×4 | **na,na,na** | ✗ | ✗ |
| B-02-S01 | na×3 | **na,na** | ✗ | ✗ |
| B-02-S06 | na×1 | **na** | ✗ | ✗ |
| B-09-S04 | na×1 | （无锚点步） | ✗ | ✗ |

**9 点里只有 1 点（`B-20-S06`）能靠改判据救回；其余 8 点的「有锚点步」L1 结论全是 `na`。**

这意味着：

1. §8.1 根因 Ⅱ 的表述会误导人。`nP` = `L1 na + L2 pass`，聚合后是 `na`，**不是「差一点 pass」**。只有拿「L2 pass 兜底 L1」才能让它们算 pass——而 L2 是量纲/系数结构检查，它 pass 只证明量纲不矛盾，**不证明式子对**。拿它判 `hit` 会系统性高估，不能做。
2. **段 1 的可判率（47%）不是段 1 的策略问题，是 L1 的 `na` 率锁死的。** 27 份金标 L1 是 `74 pass / 0 fail / 149 na`（pass 率 33%），20 份产物是 `251 / 3 / 254`（pass 率 50%）。段 1 只在「L1 或 L2 出结论」的步上才可能判分，天花板就是 L1 的覆盖率。
3. 因此 **T31 §3.4 的「15/20」在段 1 阶段结构性不可达**，不是这批 20 点运气差。

**出路三条，都不该我单方面选：**

- **甲**：把 §3.4 的抽查口径限定为「机器判 `hit`/`miss` 的点」——只验精确率。本批即 **10/10 = 100%**。`na` 点的召回率（本批 10/19 = 53%）留给段 2 之后重测。
