### 0.3 根因（我的判定，你要验证）

`验证器/l1_deduce.py:319 _per_step_one()` 的执行序：

```python
e = _subs(expr, prior)        # 326 行：把前序步算出的值代进去

if not sym or num is None:
    return _per_step_no_value(e, prior)

if sym not in names:
    return Verdict("na", ...)

try:
    sols = sympy.solve(e, Symbol(sym))    # 335 行：照解不误
...
if not nums:
    if isinstance(sols, list) and not sols:
        return Verdict("fail", "本步方程对本步符号无解（方程自相矛盾）", "E-10", "per_step")   # 346 行
```

**当本步的符号在前序步已经算过时，`_subs` 会把它一起代掉，`e` 退化成常数。**
此时 `solve(常数, x)` 必然返回 `[]`，于是走 346 行判「自相矛盾」。

**但这个常数等于 0 恰恰说明方程被前序已知完全满足。逻辑反了。**

两处实证（我 22:31 跑出来的）：

- `B-12-S06`：`v1 - 8`，前序已有 `v1=8` → 代入得**精确 `0`** → `_is_zero` 返回 `True`，但代码根本没看它，直接 solve → `[]` → fail。
- `A-08-S09`：`dt - (v0 + v2b)/a2`，前序全部已知 → 代入得 `-5.55e-17` → 浮点噪声，`_is_zero` 返回 `False` → solve → `[]` → fail。

第二处就是 G3 打勾稿里记的「残差 −5.55e-17 要求严格等于 0」。**两处是一根因，不是两件事。**

## 1. 段 A：修 L1（改代码）

### 1.1 要改成什么

在 `_per_step_one()` 里、`if sym not in names` 之后、`sympy.solve` 之前，加一个分支：

**`e` 若已无自由符号，说明没有未知量可解，此时按残差容差判，不进 solve。**

- 残差在容差内 → `pass`，detail 要说清「方程已被前序已知完全满足」，并带上本步值与残差
- 残差超容差 → `fail / E-10`，detail 要说清是「与前序已知矛盾」，**不要再说「方程自相矛盾」**
- 含不可数值化项 → `na`

**建议实现**（不强制照抄，但若你换写法，回执里要说明为什么）：

```python
if not e.free_symbols:
    kind, val = _residual(e, prior)
    if kind == "zero":
        return Verdict("pass", f"方程已被前序已知完全满足（代入残差 {_fmt(val or 0)}，容差 2%）；本步 {sym}={_fmt(num)} 与前序一致", None, "per_step")
    if kind == "bad":
        return Verdict("fail", f"方程代入前序已知后残差 {_fmt(val or 0)}（非零），与本步 {sym}={_fmt(num)} 矛盾", "E-10", "per_step")
    return Verdict("na", "方程代入后含不可数值化的项，本步不判", None, "per_step")
```

**位置必须在 `if sym not in names` 之后。** 放在前面会把「方程根本不含本步符号」的步误判成 pass。
