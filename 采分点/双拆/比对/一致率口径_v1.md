## 0. 为什么需要这份口径

70% 这道闸只有在「一致率怎么算」先说死之后才有效。否则同一份数据能算出 60% 也能算出 98%，闸门形同虚设。本文档的唯一目的：把算法写成别人可以照着复算的程度。

## 1. 比对单位

| 侧 | 来源 | 取法 |
|---|---|---|
| A 侧（双拆） | `采分点/双拆/{题号}.csv` | 全部数据行，一行 = 一步 |
| B 侧（T05b） | `原始资料/五卷力学大题_采分点总表_v2.xlsx` → `采分点总表` | `point_id` 前缀 = 题号的全部行 |

**不按 point_id 配**（两侧撞号但不同义，STATE 已定）。一律按采分点文本的**物理行为**配。

题集（10 题，与任务卡一致）：A-08 / A-09 / A-10 / B-01 / B-02 / B-06 / B-09 / B-12 / B-17 / B-19

## 2. 配对判据

一步 = 一个采分点。A 侧第 i 步与 B 侧第 j 步**配成一条边**，当且仅当两者要求考生完成的是**同一个作答动作**，即指向：

- 同一条方程（含其等价变形），或
- 同一个判断（状态/方向/过程性质），或
- 同一个待求量（同一物理量、同一位移/速度/功/热），或
- 同一小问的最终答案

**不要求**：文字相近、分值相等、类别标注相同、步序相同、解法路径相同。
**不构成配对**：仅同属一小问、仅同属一知识点、仅数值恰好相等但物理量不同。

每条边必须写一句「配的是什么」，供第三方复核——这是本口径唯一的防伪手段。

## 3. 允许一对多

现实里两个人切法不同，会出现「一方一步 ↔ 对方三步」。因此边可以一站多连，处理方式如下：

把边表看成二分图，取**连通分量**。对每个分量记 `a_c` = 其中 A 侧节点数、`b_c` = B 侧节点数。

- **双边分量**（`a_c ≥ 1` 且 `b_c ≥ 1`）：表示「这个意图双方都表达了」。计 **1 个意图单元**
- **A 单边分量**（`b_c = 0`）：A 说了、B 完全没说。计 `a_c` 个单元
- **B 单边分量**：同理计 `b_c` 个单元

## 4. 两个指标

设 `N_a`、`N_b` 为两侧步数，`K` 为双边分量个数。

**严格点对点一致率**（步级 Dice，最保守）

```
M  = Σ min(a_c, b_c)        # 二分图最大匹配的边数
P_strict = 2M / (N_a + N_b)
```

一步对三步时，严格口径只承认 1 对，另 2 步算「没配上」。这是最不利于高估的算法。

**归一后一致率**（意图级 Dice，闸门用这个）

```
n_a' = K + Σ_{A单边} a_c
n_b' = K + Σ_{B单边} b_c
P_norm = 2K / (n_a' + n_b')
```

同一切法差异被折叠掉；只有「一方说了、另一方完全没有」才扣分。

**粒度分歧度** = `P_norm − P_strict`。它不判对错，只度量两人切法差多少。这三个数一起报。

## 5. 闸与统计方式

- **G1 第三条判据：`P_norm ≥ 70%`**
- 统计方式：**10 题合并**（ΣK / Σn'），不取单题平均。合并可以避免单题小样本把均值带偏。
- `P_strict` 与粒度分歧度同时报出，**不作闸**。
- 单题也逐题报，用于定位问题题。

## 6. 两处必须单列的情形

**A-09 单列。** STATE 记载 A-09 的 T05b 版本「样张经用户认定 6＋3＋5 后入库」，即 B 侧不是纯独立产出。算入总账会污染一致率。处置：**照常比对、单列报数、不计入闸**，同时给出「含 A-09」与「不含 A-09」两组数。

**A-08 独立性瑕疵已知。** T06a 侧封存后曾读到 T05b 的 A-08 结论（详见 `自检报告.md` §8）。处置：照常比对，报告中标注该题一致率不作为独立性证据。

## 7. 已知偏向与对抗措施

配对由 T06a 拆解者本人执行，存在「倾向于把自己的每一步都配上」的系统性偏向。三条对抗措施：

1. 每条边写明配对依据，第三方可逐条推翻；
2. 另派一个**不知情子代理**做对抗审查，专门找「不该配却配了」与「该配却没配」，其修正单列；
3. 报告同时给出「对抗审查前 / 后」两组数，取**修正后**为最终值。

## 8. 本口径不做的事

- 不判谁拆得对。70% 是「可复现性」的门槛，不是「正确性」的门槛。
- 不比较分值分配的合理性（那是判分口径的活儿）。
- 不做跨题的知识点覆盖统计。
